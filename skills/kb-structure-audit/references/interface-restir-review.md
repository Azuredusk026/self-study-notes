# ReSTIR机制接口复读

范围为《ReSTIR》全文，直接对照《描边》的输入、计算、失败及章节推进。边界动作KEEP，正文动作RESTRUCTURE、DEEPEN、FACT-CHECK，标题KEEP。

复读先沿单像素采样、面积到参数域、来源合并、支持分配、递归时空数据流、当前可见性逐项追踪。正文将最终使用的连续h归一化放在数据流之前，时域与空间数例连续使用相同规则。空间本地源h(a)=4、邻居h(a)=1时，分母170，选a输出9/85；总M基线9/22在证据段单独标明适用条件。

递归反证固定场景与独立调度数据G，保留所有候选生成和替换随机性。当前新鲜池覆盖输出目标支持；M即使没有代表也累计，历史限幅只依赖外生M和K；接受集合不读取代表亮度、W或随机阴影结果。按阶段归纳任意g的贡献关系，中间池登记当前表面目标即可。源相关性不破坏这一步期望，但不提供独立样本数或无限帧收敛保证。

反例一：贡献1、3的两光，历史选a时m=1、选b时m=3，即使两遍使用相同m，均值仍为17/4而非4。反例二：只接受选b历史，均值9/2。反例三：历史仅支持a、当前新增b，枚举A及替换结果后a、b的加权质量分别为1；输出可登记当前支持。下一帧删除a时目标置零但保留来源上下文，按随机代表删除整池会破坏接受规则。
