# 跨机制接口复读记录

## 范围与方法

本轮以8504a15为正文起点，范围是55aef1c至8504a15间修订的40篇。前五篇为《快照同步》《编辑器工具的事务与批处理》《载具物理》《游戏AI导航》《ReSTIR》，其余35篇逐篇复读。判据来自《描边》的解释方式：输入具有明确含义，计算产生后续机制能消费的结果，状态转换和失败恢复可以沿正文推演。矩阵、哈希与测试分别记录复读身份及实现证据，不产生正文质量结论。
