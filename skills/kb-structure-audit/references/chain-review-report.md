## 最终反证与修正

最终复读直接回到正文，重新追踪各主要机制，并采用与主算例不同的输入。下列问题均落实到正文规则或配套实现。

| 挑战输入 | 发现的问题与现行规则 |
|---|---|
| 历史采样90%来自Q=1的颜色0.2，10%来自Q=0的颜色0.9 | 先平均Q会以0.9通过门限并混出0.27；各非零足迹先检查Q，锚点支持另行门控 |
| 遮挡区域重新生成后Q重置1 | 局部可复用不等于重新获得关键帧身份；另存A_anchor，重新生成取0，人工批准才置1 |
| 车轮胎面速度低于驻车阈值但自转尚非零 | 制动区间包含Iw乘初始轮速，候选停轮角冲量先进入车体预测；条件失败从冻结状态改走动态分支 |
| 迁移提交到B8后迟到重试同一个准备请求 | 查询既有迁移状态并返回Committed，不再次冻结B8；输入重试同时保存原摘要与原结果 |
| 发布到11后被人工编辑为12，或内容变回原值 | 发布回执和单调代次共同判断，恢复进入冲突，不覆盖人工编辑 |
| 面光面积由2变成6 | 初始面积域池进入时空缓冲前转换到参数域，W除以来源面积，当前贡献使用当前面积雅可比 |
| D3D12设备移除返回UINT64_MAX | 先识别故障哨兵再比较完成值，停止帧槽位复用 |
| 缺包达到外推上限后画面冻结 | 播放时刻r与姿态一同冻结，补足缓冲后恢复，超时通过有左右样本且不倒退的锚点重同步 |
| 平台上移1米，初始穿透恢复已经将角色推高1米 | 先求携带目标姿态，恢复当前穿透后只扫剩余携带位移，不再完整叠加平台增量 |
| 读者刚取得旧清单、尚未登记引用时发布新版本 | 取得清单和登记引用位于同一版本锁；跨进程使用先登记的版本租约 |
| 同一破坏事件在准备期间重试 | 待处理表与已应用表共同去重，同ID异参数拒绝，准备失败保留原事件身份 |
| 客户端在加速期间外推到r的姿态与权威历史不同 | r只确定查询时刻；正文展开权威历史策略、0.1米与0.2米的错失数例，以及按已发快照复现展示轨迹所需的另一套数据契约 |

最后一项区分了时间对应与姿态相同；冻结时间、缩短窗口和增加缓存都不会自动消除外推误差。正文同时解释采用的判定规则、误差来源及展示重建的输入和约束。
