# 技术断言核验

把结论拆为可验证的断言，记录原句位置、输入条件、版本、API、平台和来源定位。优先读对应规范章节、源码提交、原始论文或演讲，知乎与博客作为工程线索。

交叉检查关键语义和成本。来源冲突按版本、管线、硬件、术语、实验和错误调查。对绝对断言寻找前提和反例；性能数字记录设备、驱动、场景、分辨率、预热、窗口和统计方法。

输出断言ID、位置、条件、来源URL/源码提交、核对日期、判定和验证记录。判定使用依据支持、条件结论、实践观察、假设或未核验。HTTP成功只说明资料取得。

代码编译、引擎运行、帧捕获和性能计时分列。使用真实执行记录；数学实验仅支持测试的机制。无法确认时限定范围或记录待验证，并保留有价值的实践信息。
