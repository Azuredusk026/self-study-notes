# 代码与技术图

读取 [学习与维护方法](../../知识库/00_知识库说明/学习与维护方法.md) 的代码和图片规则。

代码分完整最小样例、机制片段和伪代码。说明语言、入口、输入输出、单位、空间、格式、版本、资源寿命及省略项。完整样例给数据、操作、预期和失败判据；编译与运行分别记录。

图片先说明要观察的技术关系。结构、空间、依赖与时序优先用Mermaid/SVG/PlantUML/Graphviz源文件。必要的技术解释才用AI图；结果证据使用真实原图、引擎截图或捕获。用户指定图保留原始用途与落点。

采用图登记于 `知识库/assets/registry.json`：ID、类型、哈希、路径、作者、来源、许可、文章/章节、图注及验证状态。许可未确定的来源图只登记候选及原文链接。图片数量按解释价值决定，装饰图不进入制作任务。

检查路径、注册、图注、来源、许可和源产物一致性。原图和模型图分别标明；可确定的关系逐边核对，真实结果核对环境。复用现有图源，避免无理由复制。
