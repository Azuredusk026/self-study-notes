# Legacy TA-Encyclopedia Migration Scope

The repository-level `../AGENTS.md` is authoritative.

This directory contains the previous one-term-per-page encyclopedia. Treat it as
migration source material, not as the target architecture.

- Do not create new pages here using the legacy templates.
- Do not expand the generated legacy indexes as part of the rebuild.
- Read and migrate useful content into the new topic-based structure.
- Record each source page's outcome in the migration ledger before deleting or
  archiving it.
- Preserve recoverability through Git and do not introduce redirect pages for
  every retired legacy note.
