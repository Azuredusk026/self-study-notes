# 课程概念覆盖审计

本审计检查公开课程笔记中的高频技术概念是否进入正式聚合文章。检查单位是可被单独解释、实现或追问的概念组，课程二级标题覆盖由章节台账继续负责。

## 审计范围

- 公开课程：Games104、图形工程、图形学、数据结构和算法、C++ 基础、编辑器设计、游戏 AI、游戏网络与 ACT；
- 正式文章：`知识库/00-21` 范围内的 70 篇聚合文章；
- 概念台账：`docs/manifests/course-concept-targets.tsv` 中的 84 个高频概念组；
- 持续检查：目标文章和证据来源存在，概念状态为终态，正文至少命中一个明确检索别名。

## 维护规则

课程笔记出现新的实现术语、公式对象、协议机制、算法或工具架构时，先判断它能否由正式文章中的现有段落完整解释。需要独立解释的内容加入概念台账，并合并到最自然的正式文章。

概念别名应选择正文和课程中稳定出现的术语，避免使用“系统”“渲染”“流程”这类宽泛词。每个概念至少保留一份公开课程证据。验证命中只证明术语进入目标文章，内容准确性仍通过课程原文、官方资料和人工复核保证。

