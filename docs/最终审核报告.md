## 来源与隐私

`docs/manifests/course-targets.tsv` 保存人工目标映射，`course-coverage.tsv` 按 H2 展开覆盖关系，`source-inventory.tsv` 只记录 Git 可公开来源。审计脚本会从人工目标表继承覆盖状态、目标文章和备注，重复运行不会把已完成来源恢复成临时状态。

任何 `文字记录/` 目录、名称含“文字记录”的私密压缩包、Obsidian 工作区状态、IDE 状态、环境变量文件和密钥都被排除。验证脚本同时检查 Git 跟踪集合和公开 manifest，防止这些内容意外进入仓库。

## 持续维护风险

- Unity、Unreal、GPU 架构、网络库和生成模型工具会持续变化。版本相关行为应优先按官方文档、规范、源代码和实际捕获更新。
- 自动检查能发现结构与覆盖问题，不能替代技术事实核验。硬件行为、性能结论和具体引擎实现仍需一手资料与实验。
- 新课程加入后必须先更新人工目标映射，再生成章节台账；不要直接把课程顺序复制成新的正式目录。
