# 术语与命名决策

## 文件和标题

- 文件名优先使用简洁中文主题，保留必要的英文缩写。
- 长英文概念使用中文加英文，例如 `时域采样（Temporal Sampling）`。
- MSAA、TAA、BRDF、PBR、PCF、PCSS、BVH 等稳定缩写不强行翻译为文件名。
- 文件名避免下划线式英文组合，例如旧的 `Deferred_Rendering.md`。
- 同一概念只保留一个正式页面。别名进入术语表或 Frontmatter aliases。

## 渲染术语

- Direct3D 语境使用“像素着色器（Pixel Shader）”。跨 API 时说明 Fragment Shader 的叫法差异。
- 使用“片元”描述光栅化生成的候选样本，不把 Fragment 直接等同于最终像素。
- `GBuffer` 作为统一写法，正文首次出现说明 Geometry Buffer。
- `Render Pass` 保留英文，因为图形 API、引擎和算法中的含义不同，正文必须指出上下文。
- `Forward+` 作为 Forward Rendering 加分块光源剔除的常用名称。

## 颜色术语

- 不把 sRGB 简化成“Gamma 空间”。sRGB 同时规定色度和传递函数。
- “线性空间”指用于物理量运算的线性数值，不表示最终显示编码。
- Alpha 默认视作线性覆盖率或材质数据。它通常不经过 sRGB 解码，但具体语义由资产和 Shader 约定决定。

## 资产和管线术语

- `Asset Pipeline` 统一称“资产管线”，不与渲染管线混用。
- `Validation` 统一称“资产验证”或“质量门禁”，避免泛化成“质检一下”。
- `Build Pipeline` 指构建、打包和发布流程。
- `Data Lineage` 统一称“数据血缘”，用于 AIGC 和自动化资产的输入输出追踪。
