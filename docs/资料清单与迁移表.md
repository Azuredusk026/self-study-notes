# 资料清单与迁移表说明

公开来源清单保存在 `docs/manifests/source-inventory.tsv`。课程章节与正式文章的对应关系保存在 `docs/manifests/course-coverage.tsv`。

## 字段

| 字段 | 含义 |
|---|---|
| `source_path` | 相对 Vault 根目录的来源路径 |
| `file_type` | 文件扩展名 |
| `bytes` | 文件大小 |
| `sha256` | 内容哈希，用于判断完全重复和追踪来源变化 |
| `title` | Markdown/TXT 中识别到的首个 H1 |
| `target_domain` | 初步归属的正式知识领域 |
| `migration_status` | 当前覆盖状态 |
| `target_article` | 实际承接知识的正式文章 |
| `notes` | 冲突、取舍和来源关系 |

## 终态定义

| 状态 | 含义 |
|---|---|
| `已覆盖` | 有效章节已经映射并进入正式文章 |
| `重复内容已覆盖` | 目标文章已有等价知识，台账记录对应关系 |
| `保留治理` | Git、规则等仍在使用的治理文件 |
| `待覆盖核验` | 尚未完成章节级映射，只能作为执行中的临时状态 |

## 使用规则

新增或更新来源时：

1. 阅读公开课程笔记，不访问 ignored 的私密原件。
2. 将有价值内容融入正式主题，而不是原样复制。
3. 在章节覆盖台账中记录标题、目标文章和覆盖状态。
4. 来源的全部有效章节收口后，将来源状态改为 `已覆盖`。
5. 在 `notes` 中记录重要取舍、冲突和待核验点。

运行 `scripts/validate-vault.ps1` 检查非终态、章节缺口和公开安全边界。
