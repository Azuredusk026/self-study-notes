# 个人游戏开发知识库

这是一套以原理、机制和工程验证为核心的个人 Obsidian 知识库。

内容覆盖图形学、游戏引擎、编程、算法、物理、Gameplay、游戏 AI、网络、工具管线和 AIGC。相关概念会放在自然主题中，尽量说明问题为什么存在、技术如何工作、代价是什么、怎样观察和验证。

当前正式知识位于 `知识库/00-21`，共 69 篇聚合主题文章。`课程记录/` 保存 89 份公开课程笔记，其中 350 个二级章节均已进入覆盖台账，50 个高频概念组进入概念级持续检查。

## 当前结构

`知识库/` 与 `课程记录/` 提供两个检索范围：

- `path:"知识库" 关键词`：只搜索整理后的正式正文；
- `path:"课程记录" 关键词`：搜索课程来源；
- `-path:"课程记录" 关键词`：在整个 Vault 中排除课程记录。

正式知识使用编号目录稳定排序：

- `01-12`：数学、图形、渲染、动画、VFX 和现代渲染；
- `13-17`：引擎与资源、性能、工具管线、编程和 AIGC；
- `18-21`：游戏物理、Gameplay、游戏 AI 和游戏网络。

课程笔记直接位于 `课程记录/<课程名>/`，使用两位序号和简短内容标题命名。正式文章负责跨课程去重和建立知识关系，`docs/` 保存覆盖台账、构建日志和审核报告。

## 公开仓库边界

`文字记录/`、私密课程压缩包、本机 Obsidian 工作区、IDE 状态、环境变量和密钥文件由 `.gitignore` 隔离。公开审计只处理 Git 可公开文件，不记录私密来源的路径、哈希或内容预览。

## 维护检查

```powershell
.\scripts\audit-vault.ps1
.\scripts\build-course-coverage.ps1
.\scripts\validate-course-concepts.ps1
.\scripts\validate-vault.ps1
```

第一条命令更新公开来源与标题清单。第二条命令按人工目标映射展开课程 H2 章节。第三条命令检查高频技术概念的来源、目标文章和正文命中。第四条命令执行完整知识库检查，并自动包含概念覆盖验证。
