# 个人游戏开发知识库

这是一套以原理、机制和工程验证为核心的个人 Obsidian 知识库。

内容覆盖图形学、游戏引擎、编程、算法、物理、Gameplay、游戏 AI、网络、工具管线和 AIGC。相关概念按自然主题聚合，重点解释问题来源、执行机制、工程代价与验证方法。

正式知识位于 `知识库/00-21`，共 71 篇聚合主题文章。

## 阅读方式

使用 Obsidian 打开仓库根目录，从知识地图进入。需要定向查找正式文章时使用：

```text
path:"知识库" 关键词
```

每篇文章的“相关主题”连接必要的前置知识、执行依赖、对照技术和延伸内容。
