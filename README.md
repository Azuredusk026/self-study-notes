# Technical Art 知识库

这是一套以原理、机制和工程验证为核心的个人 Technical Art 知识库。

它不按项目经历组织，也不把每个关键词拆成单独页面。相关概念会放在一个自然主题里，尽量回答：问题为什么存在、技术如何工作、代价是什么、怎样观察和验证。

## 范围

正式知识覆盖：

- 图形数学、采样和信号；
- GPU 与实时渲染管线；
- Shader、光照、PBR、阴影、纹理和后处理；
- 几何、动画、VFX、NPR、光追和现代 GPU 管线；
- Unity、Unreal、资源架构和性能分析；
- 美术资产、DCC、编辑器工具和版本控制；
- TA 所需编程、数据结构、AIGC 和 Agent 管线。

项目管理资料位于 `docs/`，不属于正式知识正文。
