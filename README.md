# Technical Art 知识库

这是一套以原理、机制和工程验证为核心的个人 Technical Art 知识库。

它不按项目经历组织，也不把每个关键词拆成单独页面。相关概念会放在一个自然主题里，尽量回答：问题为什么存在、技术如何工作、代价是什么、怎样观察和验证。
