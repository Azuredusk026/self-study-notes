# 旋转、四元数与插值

旋转问题通常有三个层次：怎么给人编辑、怎么在程序中保存、怎么在两个姿态之间平滑变化。欧拉角、矩阵和四元数各自适合不同层次。

## 欧拉角（Euler Angles）

欧拉角把旋转拆成绕三个轴的连续旋转。它容易在 Inspector 中编辑，但结果依赖旋转顺序。例如 XYZ 和 ZYX 并不等价。

它的主要问题：

- 同一姿态可能有多组角度表示；
- 角度跨过 180/360 度时，数值插值可能绕远路；
- 某些姿态会让两个旋转轴重合，失去一个自由度，这就是万向节锁。

欧拉角适合作为编辑器输入，不适合作为所有运行时旋转计算的内部表示。

## 旋转矩阵

3x3 正交矩阵可以表示旋转。它能直接变换向量，也方便与缩放、平移组合成 4x4 矩阵。

纯旋转矩阵的三个基向量互相垂直且长度为 1，逆矩阵等于转置矩阵。不断做浮点运算后，这些基向量可能漂移，需要重新正交化。

## 四元数（Quaternion）

单位四元数可以表示三维旋转：

$$
q=\left(\mathbf u\sin\frac{\theta}{2},\cos\frac{\theta}{2}\right)
$$

$\mathbf u$ 是单位旋转轴，$\theta$ 是旋转角。这里的四个分量不是四维位置，也不是欧拉角。

四元数的优点：

- 只用四个数保存旋转；
- 组合旋转比较稳定；
- 不会像欧拉角一样出现万向节锁；
- 适合做旋转插值。

$q$ 和 $-q$ 表示同一个空间旋转。这会影响插值路径：如果两个四元数点积小于 0，通常会翻转其中一个，使插值走单位球面的短弧。

> [!warning] 顺序问题
> 四元数乘法不满足交换律。`qA * qB` 的应用顺序取决于引擎约定，不要凭记忆跨引擎复制。

## Lerp

线性插值：

$$
\operatorname{lerp}(a,b,t)=a+(b-a)t
$$

当 $t$ 在 0 到 1 之间时，结果位于两端之间。超出范围就是外插。

Lerp 很适合：

- 数值、颜色和位置；
- UV、权重和材质参数；
- 已经在同一线性空间中的数据。

每帧执行 `current = lerp(current, target, speed * dt)` 不是固定时长动画。它是指数逼近，越接近目标越慢。固定时长应该保存起点和累计时间，再用规范化进度计算。

## 方向和旋转插值

### Nlerp

对两个四元数做 Lerp 后归一化。它便宜、稳定，但角速度不完全恒定。小角度或大量动画混合中经常足够。

### Slerp

球面线性插值沿单位球面的弧线前进。设两个单位四元数夹角为 $\theta$：

$$
\operatorname{slerp}(q_0,q_1,t)=
\frac{\sin((1-t)\theta)}{\sin\theta}q_0+
\frac{\sin(t\theta)}{\sin\theta}q_1
$$

它能保持较稳定的角速度。$\theta$ 很小时，$\sin\theta$ 接近零，工程实现通常退化到 Nlerp。

## 曲线插值

### Smoothstep

常见三次形式：

$$
f(t)=t^2(3-2t)
$$

它让区间两端的一阶导数为零，适合做平滑阈值和简单缓动。它改变的是插值参数，不改变 Lerp 本身。

### Bezier

Bezier 曲线由控制点决定。三次 Bezier 常用于路径和动画曲线：

$$
B(t)=(1-t)^3P_0+3(1-t)^2tP_1+3(1-t)t^2P_2+t^3P_3
$$

控制点不一定在曲线上。参数 $t$ 等速变化也不保证物体沿曲线匀速移动；匀速需要弧长参数化或近似查表。

### Hermite

Hermite 曲线由端点和端点切线控制。动画编辑器中的关键帧切线常可以理解成这种形式。

## 动画混合中的注意点

- 平移和缩放通常可以线性插值。
- 旋转应使用 Nlerp、Slerp 或专门的四元数混合。
- 直接线性混合旋转矩阵会破坏正交性并产生缩放或剪切。
- 多骨骼姿态混合还要明确局部空间、模型空间和加法动画的基准姿态。

## 验证方法

- 画出旋转前后的三个局部轴。
- 测试跨越 180 度时是否绕远路。
- 对比 Lerp、Nlerp 和 Slerp 的角速度。
- 给物体做长时间连续旋转，检查矩阵基是否漂移。
- 不要把 Inspector 显示的欧拉角变化当成内部一定用欧拉角计算。

### 最短弧四元数插值

输入 `a`、`b` 是归一化旋转，`t` 位于 $[0,1]$。四元数 $q$ 与 $-q$ 表示同一个旋转，但直接插值可能绕长弧：

```cpp
Quaternion SlerpShortest(Quaternion a, Quaternion b, float t)
{
    float cosine = Dot(a, b);
    if (cosine < 0.0f) { b = -b; cosine = -cosine; }
    if (cosine > 0.9995f) return Normalize(Lerp(a, b, t));
    float angle = Acos(Clamp(cosine, -1.0f, 1.0f));
    return (Sin((1.0f - t) * angle) * a
          + Sin(t * angle) * b) / Sin(angle);
}
```

先根据点积统一符号，再在夹角很小时退化为归一化 Lerp，避免 `sin(angle)` 接近零。验证时让终点四元数每帧随机取等价符号；结果应保持同一旋转路径，没有突然转一整圈。
