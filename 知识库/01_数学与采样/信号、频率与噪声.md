# 信号、频率与噪声

纹理闪烁、锯齿、摩尔纹、阴影抖动和时域噪声，都可以追溯到同一个根源：连续信号被有限采样。这一篇不谈完整的信号处理理论，只抓住一个问题：信息为什么会丢失。

## 信号和频率

信号可以是一维声音、二维图像、纹理、阴影可见性，也可以是随时间变化的像素颜色。

频率描述变化速度：

- 大块平缓颜色是低频；
- 细线、硬边和密集纹理是高频；
- 一次突变同时包含很多频率成分。

空间频率关注每个单位距离变化多少次。时间频率关注每秒变化多少次。

## 采样和混叠（Aliasing）

采样把连续信号记录为离散值。如果采样频率不足，高频信号会伪装成错误的低频信号，这就是混叠。

Nyquist-Shannon 采样定理给出的理想条件是：采样频率至少高于信号最高频率的两倍。真实图像通常不是严格带限信号，硬边甚至包含无限高频。因此实时渲染只能先过滤再近似采样。

### 混叠的频域机制

采样在频域中相当于把原信号的频谱按采样频率为间隔复制平移。采样频率足够高时，各份拷贝互不重叠，用一个低通滤波器取出中间那份就能还原信号；采样不足时，相邻拷贝互相叠进来，高频成分落入低频位置，叠进去的部分无法与原信号分离——这就是混叠不可逆的原因。

由此得到渲染中的两条直接推论：

- **先过滤，再采样**。Mipmap、各向异性过滤、带限的程序纹理，本质都是在采样前把信号带宽压到采样能力之内；
- **分辨率决定上限**。像素网格能表达的最高频率约为每两个像素一个周期。超过这个频率的细节无论怎样渲染都会出错，只能从源头移除——这也是远处高频法线需要收敛、过细几何需要切换 LOD 的信号学依据。

### 欠采样的两种形态

采样不足的表现分两种，成因不同，对策也不同：

- **走样**：频率超出采样能力，高频折回成低频。几何锯齿、纹理摩尔纹属于此类，对策是过滤或超采样；
- **重建不足**：频率没超限但重建滤波器太窄，样本之间的插值不平滑。放大图片时的模糊属于此类，对策是更好的重建核。

把这两种混为一谈是常见误区——给重建不足的图像继续加采样没有收益。

常见混叠：

- 三角形边缘出现阶梯；
- 远处棋盘纹理闪烁；
- 细栅栏产生摩尔纹；
- 高光随相机移动跳动；
- 阴影边缘出现锯齿和游动。

## 低通和高通

低通滤波保留缓慢变化，削弱高频。模糊、纹理缩小前的预过滤和 Bloom 降采样都与低通有关。

高通滤波保留快速变化。边缘检测和锐化会强调高频，也更容易放大噪声。

> [!question] 想一想
> Mipmap 为什么既能减少闪烁，也可能让远处纹理变糊？因为它在缩小前过滤高频，避免错误混叠，但同时也确实移除了细节。

## Fourier Transform

Fourier Transform 把信号从位置/时间域分解到频率域。直觉上，它是在问：这个信号由多少种不同频率和相位的正弦波组成？

离散傅里叶变换（DFT）对 $N$ 个样本直接计算通常需要 $O(N^2)$。快速傅里叶变换（FFT）利用对称和递归结构把常见情况降到 $O(N\log N)$。

实时图形中的常见用途：

- 频域卷积；
- 海面波浪频谱；
- Bloom 或大核滤波的特定实现；
- 音频和频谱可视化；
- 分析采样和重建问题。

FFT 不是“所有模糊都更快”。小核滤波、分辨率、数据搬运和变换开销都会影响选择。

## 空间噪声不是随机白点

Shader 中的噪声通常需要两个性质：可重复、空间连续。只给每个像素独立随机值会得到白噪声，邻域没有结构。

### 频谱形态对比

几种噪声在频域的区别比实现细节更能指导选型：

- **白噪声**：频谱平坦，所有频率能量相等。没有结构，直接用会得到闪烁的沙粒感；
- **Value/Perlin**：能量集中在低频，高频快速衰减，因此看起来平滑自然。Perlin 的格点梯度结构会在主对角线方向留下微弱的方向性；
- **Worley**：频谱由特征点分布决定，中高频占比更高，适合细胞与裂纹这类有明确尺度的结构；
- **蓝噪声**：能量集中在高频段，低频近乎为零。人眼对低频图案最敏感，因此蓝噪声的颗粒感最不显眼——这是它被用于抖动与采样的原因。

FBM 的逐层加倍频率、减半振幅，构造出的正是 $1/f$ 形态的频谱，与自然现象的统计特性一致，这是它看起来“自然”的数学原因。

### Value Noise

在格点生成随机值，再在格子内部插值。实现简单，但低质量插值会暴露方格方向。

### Perlin Noise

格点保存随机梯度，采样点与梯度做点积后插值。它产生连续的自然起伏，适合扭曲、云、地形和材质变化。

### Simplex Noise

把空间划分为单纯形，例如二维三角形、三维四面体。高维时参与计算的邻居比规则网格少，方向性也更均匀。

### Worley Noise

空间中分布特征点，结果由采样点到最近或若干特征点的距离决定。常见输出有 $F_1$、$F_2$ 和 $F_2-F_1$，适合细胞、裂纹和云团结构。

## FBM 和多尺度细节

分形布朗运动（Fractal Brownian Motion，FBM）把多层不同频率和振幅的噪声相加：

$$
f(\mathbf p)=\sum_{i=0}^{n-1} a_i\,noise(f_i\mathbf p)
$$

通常频率逐层增大，振幅逐层减小。低频负责大形，高频负责细节。不是层数越多越好：每层都增加采样或计算成本，高频还可能超过像素采样能力并产生闪烁。

## 时域噪声和抖动

在低采样数算法中，可以让每帧使用不同随机样本，再通过多帧累积收敛。这会把固定的结构化误差变成随时间变化的噪声。

理想的抖动需要：

- 单帧分布足够均匀；
- 多帧序列覆盖更多位置；
- 与重投影和历史拒绝配合；
- 避免肉眼明显的周期。

蓝噪声强调把能量推到高频，人眼更不容易注意，后续滤波也更容易处理。但蓝噪声不是自动正确，缩放、平铺和时序循环仍可能暴露模式。

## 验证方法

- 缓慢移动相机，观察远处纹理和细线是否闪烁。
- 暂时关闭 Mipmap 或抗锯齿，对比混叠位置。
- 显示纹理 LOD 或屏幕导数。
- 分别观察低频大形和高频细节，不要只看最终叠加结果。
- 测量噪声函数的实际 Shader 指令和采样成本。

### 用屏幕导数限制程序纹理频率

下面的 HLSL 输入是连续 UV，输出是经过像素覆盖估计的周期条纹。`fwidth` 近似当前 2x2 像素组内相位的变化范围：

```hlsl
float BandLimitedStripe(float2 uv, float frequency)
{
    float phase = frac(uv.x * frequency);
    float footprint = max(fwidth(uv.x * frequency), 1e-5);
    float left = smoothstep(0.5 - footprint, 0.5 + footprint, phase);
    float right = smoothstep(1.0 - footprint, 1.0, phase);
    return saturate(left - right);
}
```

频率接近或超过像素采样能力时，过渡带随 Footprint 变宽，减少闪烁。这只是局部低通过滤，不会恢复已经丢失的信息。把相机逐渐拉远并对比硬 `step`；硬边版本会产生摩尔纹，导数版本应平滑收敛到平均值。
