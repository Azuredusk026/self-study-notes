# GI方案选择

间接光可以保存在表面纹理、空间探针或持续更新的场景缓存中。选择先看哪些对象和灯会变化，再看目标设备能承担多少更新成本。

| 如何捕获并混合局部环境反射 | [[05_光照阴影与GI/Reflection Probe|Reflection Probe]] |
| 如何在场景变化后更新间接光表示 | [[05_光照阴影与GI/动态GI|动态GI]] |

## 阅读与选择

静态环境从Lightmap开始，动态角色接Light Probe，间接镜面使用Reflection Probe与IBL；场景本身持续变化时进入动态GI。前置是线性光照与采样模型，比较时固定曝光，分别观察间接漫反射和镜面。
