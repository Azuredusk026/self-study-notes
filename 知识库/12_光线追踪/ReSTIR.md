# ReSTIR

光源很多时，一个像素只看几次候选，容易漏掉重要贡献。ReSTIR 用一个蓄水池保存代表样本及统计量，再把附近像素和历史帧的代表样本拿到当前像素重新评价。它压缩的是候选集合；要得到正确亮度，还必须补回选择概率和样本计数。

## 单像素的重要性重采样

先讨论固定像素的直接光积分 $I=\int f(y)\,dy$。$y$ 表示光源及光源表面位置，$f$ 包含颜色贡献与最终可见性。候选按密度 $p(y)$ 产生，所有密度使用相同测度，例如光源面积与光源选择概率的联合测度。若改用立体角密度，需要同时转换几何项，不能混用数值。

以N个非退化发光三角形为一条可实现的候选路线：先以1/N选光源ID，再取两个独立均匀随机数u、v，令a=√u，重心坐标为`(1-a,a*(1-v),a*v)`。这在三角形面积上均匀，面积为Ai时，联合密度是`p(y)=1/(N*Ai)`。光源ID与重心坐标一起保存，时空重用不依赖已移动的世界坐标。退化三角形在建立光列表时排除，其ID版本同步保存；面积不同却一律填1/N，只包含选灯概率、遗漏了面内面积密度。

面积测度下，RGB贡献为`Le * BRDF * max(Nx·L,0) * max(Nlight·(-L),0) / distance² * visibility`，距离以米计；光源出射辐亮度Le、两端余弦和面积密度配套使用。重采样目标可以取这份未遮挡RGB的非负线性亮度，最终乘数才作用到含当前可见性的完整RGB。相交、自发光几何与有限距离阴影射线按[[12_光线追踪/实时光追采样]]的起点偏移和最大距离处理。点光等离散光类型采用带类型标签的独立测度，选择概率与其离散贡献成套计算，不能把点光的概率直接当成三角形面积密度。

为便宜地比较候选，选取非负标量目标函数 $\hat p(y)$，例如未遮挡贡献的亮度。它不必归一化，但应在实际贡献非零的位置为正。每个候选的重采样权重是 $w_i=\hat p(y_i)/p(y_i)$。依次累计 $S=\sum_iw_i$，第 $i$ 个候选以 $w_i/S$ 的概率替换当前代表，最终样本的选择概率就与其权重成正比。

以下是算法伪代码。`random01` 给出独立的 $[0,1)$ 随机数，所有输入权重有限且非负。零权重仍计入候选总数；全零流保持无有效样本。

```text
M = 0; S = 0; selected = invalid
for candidate in candidates:
    M += 1
    w = target(candidate) / proposalPdf(candidate)
    S += w
    if w > 0 and random01() * S < w:
        selected = candidate
if S > 0:
    W = S / (M * target(selected))
    estimate = contributionWithVisibility(selected) * W
else:
    estimate = 0
```

$W$ 是最终贡献的乘数，与更新期间的权重和 $S$ 不同。若只输出代表样本的颜色，亮光因为更常被选中，会被重复放大。条件在已生成候选集合上，最后估计的期望为：

$$\sum_i\frac{w_i}{S}\frac{f(y_i)S}{M\hat p(y_i)}
=\frac1M\sum_i\frac{f(y_i)}{p(y_i)}$$

右侧正是原候选的 Monte Carlo 估计。因此固定像素、有效支持和正确密度下，选择一个代表仍能保持期望。目标函数忽略遮挡并不自动造成偏差：最后重新计算正确可见性仍可无偏，但若代表经常被遮住，方差会很高。

### 面积测度与参数测度的交接

前面的单像素推导可以直接使用世界面积测度。跨帧面光源会变形时，本页的时空数据流统一存成`y=(稳定光ID,u,v)`参数测度，其中u、v是生成重心坐标时的两个[0,1)均匀随机数。这个平方参数域经过`a=√u`映射到三角形，面积雅可比恰好是该帧三角形面积A；单位参数面积映射成A平方米，而不是重心二维单纯形上的另一套常量。

进入初始蓄水池以前，面积域的贡献、目标和提议密度全部转换为参数域：`f_param=A*f_area`、`target_param=A*target_area`、`p_param=A*p_area=1/N`。于是候选权重`target/p`保持不变，而已归一化的贡献乘数变为`W_param=W_area/A`。若已有实现先建面积域池，就在写出初始A缓冲之前按该代表样本的源面积转换W；不能只改最终贡献，却把旧面积域W原样写入历史。下文A、B、C、H的W、当前目标与源h全部采用这份参数测度，池记录的面积版本用于重新评价来源目标。

只有一个光源、面积2平方米、面积域贡献恒为1时，均匀候选密度为1/2，单样本W_area为2。转成参数域后f为2、密度为1、W为1，估计仍为2。下一帧面积变为6平方米且对应各点贡献仍为1，当前参数贡献为6，历史参数W仍为1，得到6；直接拿旧W_area=2乘当前面积域贡献1，只会得到2，错误地保留旧面积。若光源只是刚体移动、面积没变，仍用当前位置重新算距离与两端余弦，面积不变也不代表贡献不变。

来源h同样使用来源时刻面积与几何，当前目标和最终f则使用当前面积与几何。整份光源ID被不兼容地重新编号、或来源的参数化规则整体失效时，才按预定版本规则拒绝该来源。单个光被删除或当前退化时，将其当前目标置零，该代表不进入选择，仍按后文保留来源集合、M和历史支持评价；不能看到随机选中光失效就删整池。面积变化且仍非退化时正常映射。新增ID在旧来源支持外，其h为零，由本帧候选补足。这样测度转换、动态支持与池合并使用同一份样本身份。

## 蓄水池合并与目标重评估

源蓄水池 $j$ 保存样本 $y_j$、乘数 $W_j$ 和代表的候选数 $M_j$。拿到目标像素 $x$ 时，需要重新计算这个光样本在目标表面的重要性，而不是沿用邻居的亮度。基础合并权重为：

$$w_j=\hat p_x(y_j)W_jM_j$$

将这些权重送进同一替换过程，累计候选数为 $M=\sum_jM_j$，最终仍按 $W=S/[M\hat p_x(y)]$ 归一化。这条以总计数归一化的形式要求各源覆盖相同支持。跨表面背向、可见性筛除或光源集合变化会改变支持。先把这种失配补进归一化，再把完整合并过程用于每帧的数据流。

一个离散算例可以检查“换像素就重算”的必要性。光域只有两点，提议概率各为 1/2，两个源池各生成一个候选，因而 $W_j=2$。假设这次两个源池恰好分别保留这两点。目标像素的目标值为 4 和 1，合并权重为 8 和 2；实际贡献为 2 和 5。选择概率为 0.8 和 0.2，归一化后的输出分别为 2.5 和 25，期望为 7，恰好等于两点贡献之和。较大的单次输出是低概率样本的补偿，并非一定是数值错误。

## 支持域修正与归一化

### 支持失配的能量损失

几何相容不等于采样支持相同。一个表面的法线把光源b放在背面，它生成的池就可能永远没有b；另一个表面却能受到b照明。用光域a、b在当前像素各贡献1作反例：当前池均匀提议两点，K=1；源池只支持a。两池按总计数2合并，期望相当于把积分2和积分1平均，得到1.5。多加邻居只会增加这类不完整估计的份数，不能自动补回b。

下面先给支持分区形式，再给用连续目标值分配的MIS形式。两者都保留“在当前表面选择代表，再到源表面重新评价这个代表”的两遍结构；区别在最后如何分配各源的归一化份额。

### 支持分区归一化

设源池j的有效支持为Sj，已保存的Wj满足：对任意函数g，`E[g(Yj)*Wj]=积分_Sj g(y)dy`。它表达Wj是该源支持上的贡献乘数，不要求我们知道蓄水池最终选样的精确密度。初始RIS由前文证明满足这条关系；后续池要通过同样正确的归一化继续维护它。

在当前像素用`aj=Mj*Wj*目标当前(Yj)`选择代表Y，累加S。定义选中位置被多少源覆盖：

$$D(Y)=\sum_j M_j\,1[Y\in S_j].$$

最后把总M换成D(Y)，得到：

$$W=\frac{S}{\hat p_x(Y)D(Y)}.$$

条件在输入源池上，对选择过程取期望，选中源j的概率为aj/S，故估计期望先变成`sum_j f(Yj)*Mj*Wj/D(Yj)`。再对各源池取期望，就得到：

$$\int f(y)\frac{\sum_jM_j1[y\in S_j]}{D(y)}dy=\int f(y)dy.$$

这要求当前贡献非零的位置至少由一个源覆盖。每像素的新鲜池采用覆盖全部有效光源的提议，因此即使历史漏掉某盏光，当前池仍为它提供支持。若当前提议本身没有这盏光，归一化无法凭空产生候选。支持修正还要求保留所有已接受源的M和支持评价信息；某源这次所有候选都为零、没有代表，也不等于它的支持处处为空。

上述两光反例中，当前支持为{a,b}、源支持为{a}，两池M均为1。于是D(a)=2、D(b)=1。假设这次当前池保留b、W=2，源池保留a、W=2，流式权重为2和2：选b时最终W=4，选a时W=2，条件均值为3。这个条件均值不要求等于真实积分，因为只固定了其中一种候选组合。把两个均匀初始候选的四种组合全部列出，条件均值依次为2、1、3、2，总期望才是2。朴素总M归一化对应2、1、2、1，期望为1.5。

支持不能从保留下来的光样本倒推。评价`Y属于Sj`时，要取得源表面位置、几何/着色法线、材质参数和当时采用的光源集合，按源的目标函数重新评价Y。如果源在重采样前把遮挡样本清零，还要在该源表面检查可见性；只看BRDF为正会把实际被删除的候选误当成可生成，D便偏大，图像变暗。

### 连续目标权重与来源身份

支持只判断零与非零。源目标非常接近零但仍为正时，它偶尔产生的样本可能携带很大W，二值支持仍允许它与主要来源获得相同份额，方差可能很大。可以给每个源选取非负函数hj(y)，在Sj内为正、域外为零，再让各源份额相加为1。

一个实际选择是hj(y)取该源表面的重采样目标；若源阶段删除遮挡样本，就采用目标乘相同规则的可见性。记最终代表由源s贡献，连续权重归一化为：

$$W=\frac{S}{\hat p_x(Y)}\frac{h_s(Y)}{\sum_jM_jh_j(Y)}.$$

分子必须使用真正被选中的来源s；每次池替换代表时，同时保存来源索引。流式选择仍用`Mj*Wj*目标当前`，连续权重只在最终选择后计算。对选择过程取期望再应用源池关系，各源积分的系数为`Mj*hj(y)/sum_k Mk*hk(y)`，求和为1，因此同样恢复积分。取hj为支持指示函数就退化成上一节公式。

具体地，若a处当前h0=1、邻居h1=4，两池M均为1，分母为5：同一个光a由当前池选出时分子是1，由邻居选出时分子是4，二者得到不同贡献乘数。把分子写死为当前目标，就会丢掉来源身份，前述相加为1的关系也随之失效。这种按候选来源分摊的权重是归一化用的函数，不等于蓄水池的精确选样密度。

原论文补充材料的Algorithm 1展开了第二遍源表面评价；RTXDI的`RTXDI_DISpatialResampling`保存选中邻居索引，再累加源目标乘源M，最后以选中源目标作为分子调用归一化。源码提供不同偏差修正模式，不能把所有模式笼统叫作同一个无偏实现。有限域参考按上述公式枚举选择过程。

### 两遍合并实现

本页采用连续目标权重作为时空复用的计算路线，二值支持形式用于解释和诊断。以下伪代码把两者用同一函数h表达。`accepted`由表面对应、版本和邻域规则先确定，两遍使用完全相同的源集合；每项保留池、源表面和源目标评价上下文。`targetCurrent`与h均采用同一光样本测度。

```text
S = 0; selected = invalid; selectedSource = invalid
for j in accepted:
    if reservoir[j].hasSample:
        a = targetCurrent(Yj) * Wj * Mj
        S += a
        if a > 0 and random01() * S < a:
            selected = Yj
            selectedSource = j
if selected is valid:
    denominator = 0
    for j in accepted:
        denominator += Mj * h(sourceSurface[j], selected)
    numerator = h(sourceSurface[selectedSource], selected)
    W = S * numerator / (targetCurrent(selected) * denominator)
    M = sum(Mj for j in accepted)
else:
    W = 0; M = sum(Mj for j in accepted)
```

源目标和支持约定正确时，选中源自身应贡献正分母。若分母为零、数值非有限或选中来源无法复原，本次复用发生契约错误：记录诊断，使用仍完整保留的当前新鲜池；分母检查失败时保留当前池的有效估计，并修复来源目标与支持记录。

### 递归合并的成立条件

合并结果下一帧还会被当作输入，所以证明不能只停在最后一次选样。需要维护的量是：对输出表面的支持域Sx和任意可积函数g，`E[g(Y)*W]=积分_Sx g`。这里的期望包括此前所有候选生成和池替换的随机性；它不是条件在已经实现的历史样本上的期望。下一帧即使改了光照，仍能把新的贡献函数放进g。

本页采用以下可实现的调度规则。场景、材质、光源版本和表面对应关系由本帧几何确定；邻居地址采用固定模板，或由独立于所有候选与替换随机数的地址随机流产生。历史是否接受只读取这些几何与版本数据。每个池的M即使没有代表也照常累计，历史权重采用`m=min(M,20K)`，K由预先设置的预算确定。M、接受集合和源目标h均不读取选中光源、亮度、W或随机阴影结果。渲染采样结果若反过来控制后续候选预算或来源选择，就需要另作条件分析。

把这些场景和调度数据合称G，并先固定G。池本身仍是随机的：一个源可能选a，也可能选b，两个源甚至可能来自同一个祖先。对固定G，每一项来源及m已确定，函数`c_j(y)=m_j*h_j(y)/sum_k(m_k*h_k(y))`也确定。由源池关系，对任意g有：

$$E[g(Y)W\mid G]=\sum_j\int_{S_j\cap S_x}g(y)c_j(y)\,dy=\int_{S_x}g(y)\,dy.$$

等号先消去本次替换的选择概率，再逐项使用源池的条件估计关系；求和的线性性不要求各源独立。每帧的当前新鲜池覆盖Sx，保证Sx上各来源份额之和为1。初始池满足这个关系，因此时域输出、空间输出和下一帧历史可以依次归纳。再次平均独立的调度随机性G，结论仍成立。这里固定的是外生调度，而不是某次随机采样得到的历史内容；后者不能被当作已知常量后继续套用原来的无偏关系。

这也说明中间池应如何登记支持。B或C的支持是它所属表面的当前目标为正的区域，因为本地新鲜候选提供完整覆盖，合并又只选择当前目标为正的样本。它保存当前表面和当前目标版本作为下一阶段的h上下文；不需要把所有祖先的表面递归存下去。若删除本地新鲜候选，输出支持可能只是来源支持的并集与当前目标的交集，此时仅登记当前表面就可能高估支持，下一轮归一化会变暗。

例如两个像素的空间池都沿用同一个历史代表，这两个输入显然相关。只要各自的贡献乘数仍满足上述关系，把它们一起合并仍保持期望；但它们没有提供两份独立信息，M增长也不能保证噪声按独立样本数下降。GRIS区分无偏贡献乘数与渐近收敛条件，本页的有限次递归证明不推导无限帧收敛速度。[GRIS原论文](https://cwyman.org/papers/sig22_foundationsOfReSTIR.pdf)第4.2—4.3节给出贡献乘数和分区条件，第4.4—5节另行讨论方差与收敛。

### 自适应取舍的偏差

来源集合与计数一旦依据代表样本改变，上面的固定分区函数就可能失效。取两个光a、b，贡献分别为1和3，当前池和历史池各有一个均匀候选，乘数均为2、目标处处为1。若历史选a就令m=1，选b就令m=3，当前池始终m=1。给定历史选a，本次估计对当前候选和替换取期望为`(4+2)/2=3`；历史选b时为`(4+3*6)/4=5.5`。两种历史各占一半，最终均值4.25，超过真实积分4。

将同一个m同时用于选择和归一化，仍不能消除这项偏差，因为m已经由被重用的随机样本决定。若只接受选中b的历史，选中a时直接使用当前池，均值又会成为`(4+5)/2=4.5`。亮度驱动的邻居挑选、基于随机阴影命中的历史拒绝，具有同样需要重新分析的接口。

一条便宜的工程变体可以继续采用总M归一化、历史可见性缓存或亮度截断，但各项误差要能单独解释：总M会把不支持当前光源的来源也算入分母；过时可见性改变最终被积函数；亮度截断删去尾部贡献；样本驱动的接受改变来源分布。最终重新追踪一条阴影射线只能修正当前可见性，无法补回其他三种偏差。需要保持本文递归关系时，使用前述外生调度、完整当前支持和两遍归一化；需要自适应调度时，要为实际选择分布重新构造贡献分配，而不是仅调整M。

### 历史支持与场景版本

历史池还要能评价历史支持。工程保存前帧GBuffer、材质/光源采样版本和所需变换；源目标在前帧定义，当前目标在本帧定义，两者分别求值。可见性若参与源h，需要前帧可查询的几何状态或与之匹配的可见性证据，拿当前墙体代替旧墙体不是同一个支持。只在最终着色查询可见性、重采样阶段不删除遮挡样本，可以避免这份可见性支持的历史依赖，但背面和材质目标的零值仍要修正。

动态面光源按前文统一的“稳定光ID、平方参数u/v”测度表示样本，当前贡献含当前面积雅可比，历史乘数已在初始写池时转换为W_param，源支持按当时的光几何和面积评价。若接口输入仍是世界面积域的W_area，先按源面积转换再合并；整份光ID版本重新分配或参数化整体改变时，旧样本已无法唯一映射，按版本规则重建该段历史；单个光删除仍采用前文目标置零而保留来源的规则。新增光源由当前新鲜池覆盖，旧池在新增光域上的h为零；保留旧池参与其余光域，并不要求把整个动态场景限制成共同支持。

## 一帧的时空复用

合并的计算、支持和递归条件确定以后，下一步是把它们接到一帧的数据流。下面采用一轮时域加一轮空间的完整数据流：当前候选写入A，时域结果写入B，空间结果写入C，最终着色读取C，帧结束后把C保存为下一帧的历史H。每次读取的池保存光源稳定ID、平方参数u/v（也可保存能还原它们的重心坐标）、选中参数域目标值、W_param和M，并关联产生该池的表面与目标函数版本；流式更新期间另用局部S。S和W职责不同，序列化时不能混为同一个尚未归一化的值。

### 当前候选与历史接受

像素x先从当前光源提议分布产生K个候选，按单像素重采样得到A[x]。即使历史被拒绝，这条路径也提供当前帧的估计。时域查询使用当前表面的运动向量定位H中的对应像素。教学实现采用最近像素读取，禁止线性插值池字段；光源ID和代表样本并不是可连续混合的颜色。

历史接受可以写成明确的条件链：重投影坐标在图内；对应位置保存相同的稳定表面身份；前帧表面重建到当前空间后，与当前位置相差不超过场景长度阈值；法线点积高于阈值；源材质和光源参数化版本仍可重建并映射。失败任一项，B[x]=A[x]。通过时，先把历史光源ID映射到当前光源，再由表面参数重建当前光源位置，重新计算当前像素的目标值。若某历史代表的光源已删除，本帧目标置零，该候选不参与替换，但来源的M与可评价支持仍保留在第二遍归一化；不能仅因随机选中的代表被删除，就把整份历史从来源集合中移除。整个参数化版本无法重建时，才按预先确定的版本规则拒绝该来源。相机切换使所有历史失效，物体运动则通过对象变换和运动向量跟踪对应表面。

这些条件检验的是表面对应关系，并不能证明估计器的支持域一致。比如两个法线几乎相同的表面，中间仍可能隔着一堵遮挡墙；已定义的两遍归一化仍要在通过几何接受以后执行。阈值以场景尺度和法线误差设定，本文没有用一个固定数值替代不同工程的输入契约。

### 历史计数与时域输出

以下数例始终采用连续目标归一化。当前目标在a、b上为4、1，历史源目标在两点均为1；两源支持相同，但来源目标数值不同，第二遍仍分别评价。

历史多次复用以后，M可能远大于当前K，过时统计会压过新候选。这里明确选择一种计数限制：先令m=min(M历史,20K)，将它作为本次分配给历史来源的计数，已归一化的W历史保持不变。接收历史时使用权重目标当前(y历史)·W历史·m，第二遍归一化也用同一个m；当前池使用目标当前(y当前)·W当前·K。旧池内部流式S不作为本次输入，尤其经过支持修正的W不能简单反推成统一的S/(M·目标)。在共同支持的基础池中，S与M同比缩放能保持W，这只是上述处理的一种特例。

取K=2，当前池代表a、W=2；历史代表b、W=1、M=100。本像素的目标值为目标(a)=4、目标(b)=1。历史限为40以后，两项权重分别为16和40，总计数42。第二项进入时以40/56的概率替换当前代表；若随机数0.6令历史替换当前代表，则B选b，S=56，W=56/(42·1)=4/3。若登记的M限为40，候选权重却仍按100计算，历史在选择阶段会被错误放大2.5倍，第二遍分母也与之失配。

限制后的M是重采样质量的记账量，并非独立样本数。按外生规则执行的截断降低旧信息支配程度，并满足前述递归证明；它不能恢复独立性。动态光源仍要采用参数映射与支持修正，样本驱动的自适应计数则不属于这份证明。计数限幅并不代替支持修正。本文支持修正路径把限幅后的m同时用于候选权重和支持归一化；若m由样本亮度或可见性自适应选择，这个选择也会改变估计器，需要另行分析。固定的历史年龄/计数限制与根据当前选中样本临时决定保留多少统计，不能混作同一种操作。

### 空间读取与最终着色

空间阶段读取冻结的B[x]和相容邻居B[n]，重复目标重评估与池合并，输出到C[x]。假设上例B[x]保留b、M=42、W=4/3，另一个邻居B[n]保留a、M=2、W=2，则当前像素收到的权重仍是56和16，总M=44。设邻居的源目标在a、b上都为1。最终若选a，选中来源是邻居，第二遍分子为1；本地B所属表面在a的目标为4，因此分母为42×4+2×1=170，C.W=72/(4×170)=9/85。若选b，来源是本地B，分子为1、分母为44，C.W=72/44=18/11。这里总M仍登记44，但它不能代替实际的目标加权分母。每个数字都来自源池的W、分配计数以及本次代表在各源表面的目标。

使用两个空间输出位置演示原地写回的问题：像素0先把像素1合入自己，像素1随后又读取更新后的像素0，就会间接拿回自己的候选。反过来执行则是另一个结果，单轮采样模型已经改变。因此B在整个空间调度中只读，C只写；多轮空间传播每轮交换两份缓冲，并按轮数记录额外相关性。GPU端在阶段之间建立写后读可见性，不能仅依靠不同调度命令的书写顺序。

最终在当前表面重建选中的光源点，计算完整BRDF、几何项、辐射和当前可见性，再乘C.W。只有代表样本发阴影射线时，未遮挡目标负责选择、当前可见性负责最终贡献，两者职责明确。若墙在这一帧移到光源前，继续使用历史可见值1就会输出亮光；重新追踪得到0才会形成当前阴影。历史可见性缓存是额外质量取舍，需要另设年龄和距离限制。

### 动态支持的跨帧例子

设前帧表面只能接收a，历史H的支持是{a}；当前表面转向后可以接收a和新加入的b。本帧A均匀采样{a,b}，K=1、W=2，H始终选a、W=1，本次分配给两源的m都为1。取当前目标在a、b上均为1，历史目标在a为1、b为0。

如果A选a，两项流式权重为2和1。最终样本只能是a，第二遍分母为2、来源分子均为1，所以B.W=3/2。如果A选b，权重仍是2和1：以2/3选b，分母为1，W=3；以1/3选a，分母为2，W=3/2。合并两种等概率的A结果，B在a上的加权质量为1，在b上的加权质量也为1。因此B可以用当前支持{a,b}和当前h继续进入空间阶段，而不是继续标为历史的{a}。

空间邻居若仍只支持a，就再次执行相同的源目标评价和分配，不会把缺失的b算进它的分母。帧末C保存当前表面上下文。下一帧删除a时，代表恰好为a的池产生零选择权重，但它的调度计数和旧支持上下文保留；本帧新鲜池覆盖仍存在的b。把“本次选到已删除光”改成“删除整个来源”，会形成前述样本驱动的接受，不能再用这条递归推导。

## 可见性与成本

每个候选都发阴影射线，成本随候选数增加。先按未遮挡贡献重采样、只对最后代表发射线，可以把昂贵的可见性查询集中到少数样本。运动遮挡物出现时，重新求可见性仍有必要；直接沿用历史遮挡会使阴影滞后。

ReSTIR 额外保存池数据，执行重投影、邻域读取与目标重评估。复杂 BRDF 或大量邻居会让这些成本超过节省的射线工作。比较时分别记录候选生成、时域、空间、最终阴影和命中着色，使用未降噪结果检查估计均值，再检查降噪后的稳定性。
