# 景深与运动模糊

失焦和运动都会让一个表面点覆盖更多像素，但前者来自光学焦平面，后者来自曝光期间位移。两种模糊都要解决前后景混色，因此先生成CoC或速度，再在深度约束下分层采样。

## Depth of Field

景深根据镜头参数和深度估计 Circle of Confusion（CoC）。焦平面附近 CoC 小，前景和背景离焦区域 CoC 大。

实现难点：

- 前景模糊会覆盖后方清晰像素；
- 深度边界容易漏色；
- 半透明没有可靠单层深度；
- 大 Blur Radius 成本高；
- Bokeh 形状和能量需要控制。

### 薄透镜与像素半径

设焦距为 $f$、对焦距离为 $z_f>f$、物体正深度为 $z>0$、光圈值为 $N$。孔径直径为 $f/N$；薄透镜像距为 $v(z)=fz/(z-f)$。固定成像平面在 $v(z_f)$ 后，用相似三角形比较离焦光束与孔径，可得带符号的弥散圆半径

$$
r_{sensor}=\frac{f^2}{2N(z_f-f)}\frac{z-z_f}{z}.
$$

本页规定近景为负、远景为正。$f,z,z_f$ 与传感器宽度使用同一长度单位。若水平分辨率为 $W$、传感器宽度为 $S_w$，像素半径为 $r_{px}=r_{sensor}W/S_w$，不能把直径当半径使用。

```hlsl
float CoCRadiusPixels(float depth, float focusDistance, float focalLength,
    float fNumber, float sensorWidth, float imageWidth)
{
    float radius=focalLength*focalLength /
        (2.0*fNumber*(focusDistance-focalLength));
    return radius*(depth-focusDistance)/depth*imageWidth/sensorWidth;
}
```

这是HLSL机制函数，输入满足上述正值条件。50 mm焦距、f/2、对焦2 m、36 mm传感器宽和1920像素时，1 m处半径约为-17.09像素，2 m处为0。扩大光圈值会缩小半径；近裁剪面附近的半径可能极大，实际采样设置上限并记录截断误差。

### 前后景覆盖

只按中心像素的CoC搜索邻域，清晰背景像素的半径为零，就无法接收前景失焦物体扩散过来的颜色。收集时还需检查邻居自己的半径：邻居 $i$ 到目标像素的距离小于 $|r_i|$ 时，它才覆盖目标。圆盘核的理想权重与 $1/(\pi r_i^2)$ 成正比，因此大光斑应把同一份能量分散到更多像素，不能每个覆盖像素都写完整颜色。

屏幕实现通常将近景和远景分别保存预乘颜色与覆盖，先求远景背景，再将近景覆盖合成在前。收集需要限制最大搜索半径、逐样本检查深度和CoC，并归一化有效核权重。近景覆盖扩张或最大半径分块有助于找到来自邻居的贡献，但会引入过覆盖近似。单层颜色图没有被前景挡住的背景，即使覆盖计算正确，也仍需填补或接受缺失信息。

## Motion Blur

运动模糊使用相机和物体 Motion Vector 沿运动方向采样。只用相机矩阵无法处理骨骼、顶点动画和独立物体运动。

### 快门时间与速度单位

若运动向量为当前UV到上一帧UV的位移 $v=u_{prev}-u_{current}$，帧间隔为 $\Delta t$、快门曝光时间为 $t_s$，则常速假设下的曝光轨迹长度是 $v\,t_s/\Delta t$。180°快门意味着 $t_s=\Delta t/2$，因此轨迹只有一帧位移的一半。像素单位速度先除以对应宽高，NDC单位位移则先按纹理轴向和二分之一尺度转换。

一个尾随式均匀快门近似可在 $u_j=u+(j+0.5)v(t_s/\Delta t)/M$ 采样，$j=0,\ldots,M-1$，将有效颜色加权求和再除以权重和。该表达把当前画面沿轨迹收集，不能恢复过去真正被遮挡的表面；完整光学积分应考虑曝光期间的可见性。零快门时间直接返回中心颜色。

需要限制最大像素半径，处理深度边界和前后景速度差。当前像素自己的速度不足以表示邻近快速物体扫过它的覆盖范围，实际方法常结合邻域最大速度和深度分类。骨骼与顶点动画需要前后姿态位置，不能仅由相机矩阵推导。TAA投影抖动通常应从几何运动中剔除，否则静止场景也会模糊。

## Lens Effect

Vignette、Chromatic Aberration、Film Grain、Lens Distortion 可以塑造镜头感，但它们通常在显示链后段工作。

这些效果不应遮盖曝光、颜色空间或上游渲染错误。Chromatic Aberration 和 Grain 还会降低 TAA/压缩后的细节稳定性。

## 资源与调度

景深和运动模糊都读取线性颜色、深度及辅助数据；前者的CoC以像素半径保存，后者的速度在本页约定为UV位移。低分辨率缓冲中的半径要按该缓冲分辨率换算，不能沿用全分辨率数值。

先景深后运动模糊或反过来都会改变边界与高亮形状，两种操作一般不交换。宿主需固定资源生产顺序，记录透明物体是否提供深度/速度、UI在哪一阶段合成，以及相机切换时如何重置历史。Lens Effect的排列按同样的颜色与时域契约确定。

## 验证方法

固定焦距移动焦平面，检查近远CoC符号及前景覆盖。静止相机下移动骨骼角色核对物体速度；设置曝光比例为零时运动模糊消失。镜头颗粒与色差是附加显示效果，不能用来掩盖上游编码错误。
