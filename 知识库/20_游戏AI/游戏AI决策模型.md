# 游戏AI决策模型

游戏AI决策连接事实、目标选择、计划和动作执行。守卫从巡逻进入交战，受伤后撤退；读者可以沿下面的路线理解这次决定怎样取得资源、停止旧动作并恢复未完成请求。

| [[20_游戏AI/状态机与行为树]] | 模式切换和跨帧行为如何进入、取消并完成清理。 |
| [[20_游戏AI/效用评分与目标规划]] | 可行目标如何评分，并展开为可执行的有序计划。 |
| [[20_游戏AI/决策计划提交]] | 规划候选如何经过校验并原子安装成执行树。 |
| [[20_游戏AI/计划终态与重规划]] | 计划结束或站位失效后怎样续行并限制重复失败。 |
| [[20_游戏AI/决策日志与恢复]] | 决策与世界效果如何登记、去重并在退出后恢复。 |
