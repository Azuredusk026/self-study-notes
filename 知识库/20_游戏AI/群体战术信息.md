# 群体战术信息

每个NPC都扫描全场景，成本会随群体增长，而且容易读到不该知道的真实位置。群体战术信息先按感知权限收集带时效事实，再把威胁与控制写入空间场，供导航和决策查询。

## 群体与战术信息

群体移动可从分离、对齐、聚合三类局部规则开始。它们能形成自然队形，但不了解关卡目标与门口拥堵。实战通常把全局导航走廊、局部避障、队形槽位和通行优先级组合起来。

影响图把危险、控制力、资源或视野写入 Grid/NavMesh 区域。AI 可查询安全路线、薄弱侧翼和集火区域。不同信号要有衰减和更新时间，不能把过期敌情当成实时真相。战术点则预先或运行时标记掩体、射击位和观察点，并按距离、暴露度、队友占用等评分。

影响图的更新分源写入与扩散衰减两步：每个单位把影响力写入所在格子（威胁写正值、资源用另一层写正值），随后每层向邻居做若干轮扩散，每轮强度乘衰减系数 $\alpha<1$。空间权重与轮数决定传播范围，跨时间的衰减和源刷新策略决定记忆；二者分别配置。常见分层是即时威胁层高衰减快更新、战略控制层低衰减慢更新。查询时读查询点周围一个小邻域的积分而不是单点，否则单位沿格子边界移动时评分会跳变。

## 感知预算与信息抽象

每个 NPC 每帧扫描所有对象是典型的 $O(N^2)$ 陷阱。可先用空间索引筛选邻近对象，再按距离和重要性分层更新。视线检测可以分帧，远处单位降低频率，关键事件通过消息直接唤醒。

AI 应读取游戏允许它知道的信息，而不是直接遍历玩家组件。最后看见位置、声音方向和估计威胁都带不确定性与过期时间。这样既便于公平性控制，也便于调试“AI 为什么知道玩家在这里”。

## 影响场更新

伪代码输入非负威胁层，扩散算子与边界规则确定是否守恒，衰减alpha位于[0,1]。

```text
field = alpha * Diffuse(field, boundaryPolicy) + visibleSourceContributions
score = IntegrateLocalNeighborhood(field, queryPosition)
```

## 扩散、注入与记忆

传播半径与时间记忆需要分开。对规则网格，每轮把本格和邻居加权平均，权重和为1，再乘时间衰减系数，最后加入本轮允许感知的源。关闭源后场会衰减；持续源不断注入时可能达到平衡值，不能把源幅度误当最终场的峰值。

```text
next[i] = decay * ((1-k)*field[i] + k*mean(field[neighbors(i)])) + source[i]
swap(field, next)
```

这是双缓冲离散模型，`decay`和k在[0,1]，边界采用有效邻居平均，无邻居时保留自身。双缓冲让每格读同一轮旧值；原地更新会使结果依赖遍历方向。若希望半衰期H秒、更新步长dt秒，取 `decay=2^(-dt/H)`，便能用时间解释记忆，而不是把迭代次数直接当秒数。

墙体若不阻断邻接，威胁会穿墙扩散。以导航连通区域定义邻居可以限制传播；视觉威胁还要结合视线。查询结果携带最后观测时间和置信度，评分高并不代表敌人现在仍在该处。

## 验证方法

关闭源检查预期衰减，跨网格边界检查评分连续。记录事实来源、更新时间和查询权限，窄门与对冲检查局部避障，主算法见游戏AI导航。
