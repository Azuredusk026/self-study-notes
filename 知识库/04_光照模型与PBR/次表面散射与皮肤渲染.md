# 次表面散射与皮肤渲染

标准 BRDF 假设光在表面某一点进入、同一点离开。皮肤、玉石、蜡、树叶和牛奶不满足这个假设：光穿入表层，在内部多次散射后从邻近位置射出。用纯 BRDF 渲染皮肤，结果会像塑料——明暗交界线过硬，耳廓和鼻翼缺少透光的红色。

描述这类传输的是 BSSRDF，它比 BRDF 多两个位置参数，表达"从哪进、从哪出"。实时方案的核心工作，就是在不做真正体积路径追踪的前提下近似这个空间扩散。

## 扩散剖面

把一束无限细的光垂直打在半无限介质上，出射辐射亮度随离入射点距离的衰减曲线称为扩散剖面（Diffusion Profile）。它是次表面散射的核心数据。

皮肤的剖面有强烈的波长依赖：红光的平均自由程远大于绿光和蓝光。这正是明暗交界处泛红、薄部位（耳朵、鼻翼、手指边缘）透出橙红色的原因。因此剖面必须按 RGB 分别存储，用单通道灰度做模糊无法得到皮肤的正确色偏。

常用的解析近似是多个高斯的加权和，或 Burley 提出的归一化 Diffusion：

$$
R(r)=\frac{A}{8\pi r}\left(e^{-r/d}+e^{-r/(3d)}\right)
$$

$r$ 是表面距离，$d$ 由平均自由程决定，$A$ 是表面反照率。$d$ 越大扩散越远、皮肤越"软"。

引擎参数通常暴露为散射颜色与散射距离两项，两者共同决定 $d$ 的 RGB 分量。改散射颜色实际是在改各波长的扩散半径，不只是给结果染色。

## 三类实时方案

| 方案 | 求解域 | 主要成本 | 适用 |
|---|---|---|---|
| 预积分查表 | 逐像素、无邻域 | 一次纹理采样 | 移动端、大量角色 |
| 屏幕空间卷积 | 屏幕邻域 | 一个全屏 Pass | 主机与 PC 主角 |
| 纹理空间扩散 | UV 空间 | 每角色一张 RT | 影视级近景 |

三者不互斥。移动端项目常只用预积分；高端项目常以预积分打底、屏幕空间卷积补足邻域扩散。

## 预积分次表面散射

这是成本最低的方案，核心洞察是：既然扩散范围由剖面决定、局部形状由曲率决定，就可以把两者的组合结果离线积分成一张查找表。

### 表的两个维度

查找表以 $N\cdot L$ 为横轴、曲率为纵轴。

横轴用 $N\cdot L$ 而非 `saturate(N·L)`，必须保留负值区间——次表面散射最显著的视觉特征恰恰是光越过几何明暗界线、渗入本应全黑的暗面。把负值裁掉，这个效果就消失了。实际映射常写成 $u=N\cdot L\cdot 0.5+0.5$，把 $[-1,1]$ 铺满 $[0,1]$。

纵轴是表面曲率。曲率大（鼻尖、指节）时，相同的物理扩散距离覆盖更大的法线变化范围，散射看起来更强；曲率小（额头、脸颊）时散射表现平缓。曲率可以从世界空间位置与法线的屏幕导数估算，也可以离线烘焙成贴图——后者稳定得多，因为屏幕导数在边缘和 Mipmap 过渡处噪声明显。

### 采样与法线分层

另一个关键手法是对法线分层。高频法线贴图应当继续驱动高光，但不应驱动散射——散射本身就是低频现象。做法是准备一条从几何法线到完整法线贴图法线的插值，用较平滑的那条算散射项：

```hlsl
// curvatureTex 为离线烘焙的曲率，paramTex.x 为逐像素散射强度遮罩
float3 sssNormal = normalize(lerp(normalWS, geomNormalWS, _NormalSmoothFactor));
float  NoL       = dot(sssNormal, lightDirWS);

float2 lutUV;
lutUV.x = clamp(NoL * 0.5 + 0.5, 0.01, 0.99);
lutUV.y = clamp(1.0 - curvature * _SSSIntensity, 0.01, 0.99);

float3 sssDiffuse = SAMPLE_TEXTURE2D(_PreintegratedLUT, sampler_LUT, lutUV).rgb;
```

UV 两端各留 0.01 的余量，避免双线性过滤在边界取到相邻行或钳位重复。查找表必须按线性数据导入，不能标记 sRGB，否则色偏会被二次编码。表本身分辨率不必高，横向 64、纵向 32 通常足够，但要关闭该纹理的压缩——块压缩会在平滑梯度上产生可见色带。

验证方法是让方向光绕头部水平旋转一周：明暗交界处应始终有一条柔和的红色过渡带，并随曲率变化宽窄。交界处出现硬边说明 $N\cdot L$ 被提前 `saturate`；红色过渡带宽度处处相同说明曲率维度没有真正参与采样。

### 边界与代价

预积分是逐像素的，不读取邻域，因此无法表达真正的空间扩散：

- 阴影边缘不会变软。Shadow Map 投下的硬边仍然是硬边，因为散射发生在 $N\cdot L$ 项内部，而不在可见性项上；
- 薄部位透光（耳朵背光时透出红色）需要单独的 Transmission 项，通常用厚度图配合背面 $N\cdot L$ 求解；
- 纹理细节不会被散射模糊，毛孔和痘印仍然锐利。

代价只是一次纹理采样，因此它在移动端几乎是唯一可行的选项。

## 屏幕空间次表面散射

屏幕空间方案直接在图像域做扩散：先把皮肤区域的漫反射结果单独渲出，再按扩散剖面做一次加权模糊，最后叠加回主画面。它能解决预积分做不到的邻域问题——阴影边缘会真正变软，纹理细节会被恰当柔化。

### 可分离近似

二维卷积代价是 $O(n^2)$。Separable SSS 的做法是把二维核近似成横向与纵向两次一维卷积，代价降到 $O(n)$。严格来说高斯和的二维核不完全可分离，但在皮肤这类内容上的误差可以接受。

核权重按 RGB 三通道分别给出，典型的七抽样核形如 `(0.727, 0.902, 0.946)` 为中心权重，向外各抽样的红色分量明显高于绿蓝——这正是波长依赖在实现中的体现。

### 深度感知的采样半径

扩散半径由物理距离决定，但卷积在屏幕空间进行，因此像素半径必须随深度缩放：同一块皮肤在近景占很多像素、远景只占几个，用固定像素半径会让远处的脸糊成一团。

```hlsl
float linearDepth = LinearEyeDepth(SampleDepth(uv));
// _DistanceToProjectionWindow 由 FOV 与目标高度决定
float2 stepUV = _SSSWidth * _DistanceToProjectionWindow
              / max(linearDepth, 1e-4) * _TexelSize * blurDirection;
```

`blurDirection` 在横向 Pass 取 $(1,0)$、纵向取 $(0,1)$。

### 边界泄漏

屏幕空间方法最大的问题是采样会越过物体边界，把背景或衣物的颜色吸进皮肤。两道防线：

其一，用模板标记皮肤区域，卷积只在标记像素上执行。这同时也是性能优化——全屏执行代价高且毫无意义。

其二，逐抽样比较深度，深度差超过阈值就降低该抽样的权重，退回中心颜色：

```hlsl
float depthDelta = abs(sampleLinearDepth - centerLinearDepth);
float weight = saturate(depthDelta * _DepthFalloff);
sampleColor = lerp(sampleColor, centerColor, weight);
```

HDRP 的实现还额外比较颜色差异，抑制从高对比区域吸入异常颜色。

### 管线集成

HDRP 的做法是：Forward/Deferred 阶段把次表面材质的漫反射照明写入独立的 Irradiance 目标，并用模板标记该区域；随后由 Compute Shader 在标记区域执行可分离卷积；最后用一个 `Blend One One` 的全屏 Pass 把卷积结果叠加回主颜色。

叠加采用加法而非替换，意味着散射结果是对原着色的补偿，高光等非散射项不受影响。这套 Pass 的模板比较为 Equal，配合前面写入的标记位——项目需要统一模板位分配，否则会与描边、后处理遮罩等系统冲突。

## 皮肤的其他分层

完整的皮肤材质不只有散射。常见分层：

**双层高光**。皮肤表面有油脂层与角质层两重反射。用两套粗糙度各算一次镜面反射再叠加，能同时得到集中的油光与柔和的整体光泽，比单层 GGX 更接近真实皮肤。

**偏红的 AO**。皮肤内部的多次散射让凹陷处并非中性变暗，而是偏向红色。把 AO 颜色向红色偏移，比直接乘灰度 AO 更符合观察。

**Transmission**。背光时耳廓、鼻翼、手指边缘透光。用厚度图配合背面方向的光照求解，独立于正面的散射项。

**眼睛与嘴唇**。它们的散射特性与皮肤不同，通常需要独立材质与独立参数，不应复用同一套剖面。

## 验证方法

- 主光绕头部旋转一周，检查明暗交界的红色过渡带是否连续、是否随曲率变化。
- 关闭散射项对比，交界处应从硬边变为柔和过渡；若无差别，说明散射结果没有真正参与合成。
- 背光检查耳廓与鼻翼是否透光，这一项由 Transmission 而非散射负责。
- 在皮肤与衣物、皮肤与背景的边界检查是否有颜色泄漏。
- 把相机从近景拉到远景，确认屏幕空间卷积半径随深度收缩，远处的脸不应糊化。
- 用帧捕获确认卷积 Pass 的模板比较确实限制在皮肤区域，而非全屏执行。
- 单独输出查找表采样结果，确认 UV 两个维度都在有效范围内变化。
