# 算法与数据结构导读

算法决定状态怎样推进，数据结构决定这些状态怎样保存与查询。工程中先写清工作负载，再在求解、容器、图和空间索引四条路线里选择。

## 专题入口

| 工作负载 | 入口 |
|---|---|
| 状态、操作与求解方法 | [[16_编程与数据结构/算法设计]] |
| 查找、更新、有序访问与引用稳定性 | [[16_编程与数据结构/容器选择]] |
| 依赖、可达关系与路径成本 | [[16_编程与数据结构/图搜索]] |
| 位置、范围与近邻查询 | [[16_编程与数据结构/空间索引]] |

## 阅读路线

离线求解和规则转换从算法设计进入；查找、更新和有序访问进入容器选择；依赖、可达与最短路进入图搜索；位置、范围和近邻进入空间索引。选择时同时检查数学正确性、内存布局和规模增长后的成本。

## 选择示例

资产构建器要决定任务顺序时，先进入图搜索，明确依赖边与环诊断；随后在容器选择里决定节点 ID 到记录的查找结构。角色附近对象查询先进入空间索引，用全量扫描验证候选覆盖，再依据内存布局调整热数据。这些路线共享数据，但各自有独立的正确性条件。

## 实现与证据
