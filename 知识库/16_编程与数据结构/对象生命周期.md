# 对象生命周期

对象从场景消失，资源却可能仍被事件、任务或缓存引用。对象生命周期先确定拥有者与借用关系，再区分GC可达性和确定性释放。引用链解释为何仍活着，完成条件解释何时允许回收。

## 所有权

每个资源要回答：谁创建、谁拥有、谁可借用、何时释放、异步任务是否仍在使用。

C++ 使用 RAII、`unique_ptr`、容器和明确句柄；C# 使用托管引用、`IDisposable`、`using` 和引擎资源 API。GC 只管理托管内存，不会自动正确关闭 File、Socket、Native 句柄或 GPU Resource。

终结器时间不确定，也会增加 GC 工作。原生资源应提供确定性 `Dispose/Release`，并让重复调用安全。

## 托管堆与垃圾回收

C# 托管对象分配后由垃圾回收器追踪可达性。对象不可达不等于立刻释放，集合会在特定时机扫描、移动或回收。

不同 .NET/Unity 运行时的 GC 实现和 Generation/Incremental 行为有差异，应以当前平台文档和性能分析器为准。

实时程序关注：

- 每帧分配速率；
- 集合频率和暂停时间；
- 存活对象集大小；
- 大对象与碎片；
- Native/Managed 双份内存；
- 临时分配峰值。

“这一帧 GC 没运行”不代表分配免费。分配会增加未来回收工作和峰值。

## 常见 C# 隐式分配

- 字符串拼接、格式化和 `Substring`；
- LINQ Enumerator/闭包；
- Lambda Capture；
- 装箱；
- 每帧创建列表/数组/Dictionary；
- API 返回新数组；
- 异步状态机和 Task；
- 日志参数和栈 Trace。

不要因此全面禁止 LINQ 或 String。编辑器工具和低频操作更重视可读性；运行时热路径用性能分析器定位后再替换。

复用集合时 `Clear()` 通常保留容量。它减少重分配，但也可能让一次峰值后长期占用大数组。

## 原生容器与固定地址

Unity NativeArray/NativeList 等使用原生内存，并配合任务/Burst 和显式生命周期。分配器类型表达 Temp、TempJob、Persistent 等预期范围。

忘记 `Dispose` 会产生原生泄漏。过早释放而任务仍在运行会造成非法访问。

固定地址托管对象让 GC 不能移动该对象，方便 Native 互操作，但长时间大量 Pin 可能增加碎片。更稳妥的是使用固定 Native 缓冲或短时间 Pin 并批量传输。

## 资源引用与泄漏

常见“泄漏”不是内存永远无法释放，而是仍有引用：

- 静态集合/事件；
- 闭包/Task；
- 编辑器 Window 缓存；
- Addressables 句柄未释放；
- AssetBundle 依赖引用；
- 原生插件句柄；
- 对象池长期持有实例；
- 自建 `RenderTexture` 未释放硬件资源或销毁对象，或 `ComputeBuffer` 未调用 `Dispose`。

内存快照应看引用链、Native Size、Managed Size 和增长趋势。只看到总内存高，不能直接判断泄漏。

## 生命周期契约

机制伪代码先停止新使用，等待已拥有的任务，再解除订阅和释放原生资源。GC回收包装对象是后续独立步骤。

```text
StopAcceptingWork()
CancelOwnedTasks()
WaitForOwnedTasksToComplete()
UnsubscribeCallbacks()
ReleaseNativeResources()
DropManagedReferences()
```

## 拥有、共享与借用

唯一所有者负责销毁，借用者只在约定期间访问。C++的 `unique_ptr` 用移动交接唯一所有权，`shared_ptr` 让多个所有者共享控制块，最后一个强引用离开时销毁对象。互相持有强引用形成环时，两边计数都不会归零；非拥有关系用 `weak_ptr`，访问时通过 `lock()`临时取得有效强引用。

托管可达性解决另一类问题：长寿命事件发布者保存委托，委托引用订阅者，订阅者就仍然可达。把场景对象从列表移走没有切断这条链。因此销毁过程先停止接收新任务，再取消并等待旧任务真正结束，解除订阅，最后释放原生资源。发出取消信号并不等于任务已停止访问内存。

以一个纹理加载对象为例，它拥有文件流、解码任务和上传缓冲。文件读取完成后才能关流，解码完成后才能复用像素缓冲，GPU完成上传后才能归还上传区间。三个完成条件分别记录，包装对象被GC回收不能替它们决定安全时间。

## 验证方法

重复创建销毁并保存前后内存快照，追踪剩余引用链。测试异常、取消和重复Dispose，记录托管与原生内存；GC未运行的一帧不能证明分配免费。
