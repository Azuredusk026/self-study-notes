# C++工程边界

设编辑器加载资产插件M，先创建缓存B，再在界面线程T创建解码器A。A借用B的缓存页，后台任务W处理资产，T还管理A的窗口和COM接口。用户关闭A时，W尚未退出，随后又要求卸载M。宿主要分别保证声明和字节契约、对象与模块寿命、清理线程与执行次序。

对象借用决定B必须保留多久，模块关闭决定代码何时能卸载，资源收尾决定操作在哪个线程、按什么次序完成。阅读关闭协议前，先掌握接口篇的对象表、使用令牌、依赖边和唯一关闭记录。

## 验证方法

分别制造缺符号、ABI版本不匹配与加载缺库，确认诊断阶段准确。测试空指针、字段size和成对释放；编译器私有容器不跨稳定插件接口。通用所有权见对象生命周期。

## 实现与证据

C ABI声明是接口片段。版本前缀、错误输出、模块引用与线程要求按正文资料解释；关闭步骤、协调者代次、结果收件表及清理授权是本文定义的宿主协议。正文沿A、B、T推演关闭与接管，未编译动态库、加载宿主或执行实际COM异步撤销。
