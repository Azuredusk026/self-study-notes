# 动画压缩、面部、布料与毛发

角色动画的成本不只在蒙皮。Clip 数据量、解压访问、面部通道、布料和毛发的二级运动都会影响内存、CPU、GPU 与制作流程。

- [[09_动画系统/动画压缩、轨道量化与运行时解码]]：动画压缩在轨道精度、解码成本和随机访问之间取舍。
- [[09_动画系统/面部变形、口型与表情控制]]：面部动画把骨骼、形状目标与程序参数组合为连续表情。
- [[09_动画系统/布料与毛发的表示、碰撞和LOD]]：布料和毛发用低成本模拟代理驱动高密度渲染表示。

## 验证方法

- 对压缩前后计算 Joint Rotation、End Effector Position 和 Root Motion 误差。
- 在不同角色 LOD 记录 Clip 内存、解压时间、Bone Count 和 Skinning 时间。
- 对面部检查极值、组合表情、口型同步和拓扑版本。
- 用低帧率、暂停恢复、Teleport 和碰撞极限测试布料。
- 分开统计 Cloth Simulation、Skinning、Hair Simulation、Hair Rendering 和 Shadow 成本。

### 量化轨道解码

平移关键帧可在每条轨道的最小值和最大值之间量化为 16 位整数。运行时解码只需要轨道范围和量化值：

```cpp
Vec3 DecodeTranslation(U16Vec3 q, Vec3 minimum, Vec3 maximum)
{
    Vec3 unit = Vec3(q) / 65535.0f;
    return minimum + unit * (maximum - minimum);
}
```

常量轨道应单独编码，避免 `maximum - minimum` 接近零时浪费数据。压缩误差要在模型空间末端测量，因为父关节很小的旋转误差会在长骨链上放大。验证时同时记录局部分量误差和手脚末端的世界空间最大偏差。
