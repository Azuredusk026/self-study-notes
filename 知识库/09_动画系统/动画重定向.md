# 动画重定向

同名骨骼不等于同一坐标。源角色比目标腿长，直接复制平移会改变骨长，直接复制旋转也可能因参考轴不同扭转。重定向先建立绑定姿态映射，再处理根位移与末端约束。

## Retargeting

Retargeting 把源 Skeleton 动作映射到目标 Skeleton。即使骨骼名称对应，比例、Bind Pose、轴向和 Twist Joint 也可能不同。

常见步骤：建立骨骼映射、对齐 Reference Pose、处理 Root/Pelvis 位移比例、转移局部旋转、重新求解手脚 IK，再做肩膀和扭转修正。

只按骨长比例缩放全部 Translation 容易破坏动作。多数 Joint 应主要传递 Rotation，Root/Pelvis 和 IK Goal 才需要专门处理位移。

## 重定向数据流

这是算法伪代码，局部旋转映射由两端参考基底确定，位移只对指定根或目标节点缩放。

```text
map = MatchJoints(sourceSkeleton, targetSkeleton)
align = ReferenceBasisTransform(map)
targetLocalRotation = ApplyBasisMapping(sourceLocalRotation, align)
targetRootMotion = ConvertRootMotion(sourceRootMotion, scalePolicy)
SolveTargetEndEffectors(targetPose, goals)
```

## 验证方法

先比较参考姿态，再用举手、跨步与扭转动作检查。记录手脚目标误差、Twist分配与根运动；缺失骨骼明确回退，按名称猜映射只作为候选。
