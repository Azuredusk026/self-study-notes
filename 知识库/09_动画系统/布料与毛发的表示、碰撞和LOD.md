# 布料与毛发的表示、碰撞和 LOD

布料和毛发用低成本模拟代理驱动高密度渲染表示。角色变形、碰撞、重置与多级 LOD 是它们共享的集成问题，约束公式见物理专题。

## 布料的表示层级

布料可以按成本分为：

1. 烘焙在 Clip 中的辅助骨骼；
2. Spring/Dynamic Bone；
3. 低模 Physical Mesh 的实时 Cloth；
4. 高质量离线模拟或缓存播放。

渲染网格通常太密，不能直接作为模拟网格。Physical Mesh 用更少粒子求解，再通过 Skin/Wrap 映射驱动渲染网格。

## 从质点弹簧到 PBD

质点弹簧模型对粒子施加重力、风、阻尼和弹簧力。显式积分在刚性高、步长大时容易爆炸，需要小 Time Step。

Position Based Dynamics（PBD）直接迭代修正位置，使距离、弯曲、碰撞等约束接近满足。其稳定、可控，适合实时布料。典型帧流程：

1. 外力预测位置；
2. 构建碰撞约束；
3. 多次迭代 Stretch/Bend/Collision；
4. 由位置变化更新速度；
5. 把模拟网格结果映射到渲染网格。

更多 Substep 和 Iteration 通常更稳定，但成本线性增长。普通 PBD 的刚度还会随迭代数和步长变化；XPBD 用 Compliance 改善参数与步长的依赖。

## 碰撞与穿插

角色碰撞常用 Capsule/Sphere 近似身体。碰撞体过小会露皮肤，过大则让衣服悬空。

Self Collision 成本高，尤其多层衣物。常见工程手段包括：

- 降低模拟网格密度；
- 增加 Substep 并限制最大速度；
- 使用层级、厚度和碰撞组；
- 对身体使用 SDF；
- 在不重要区域关闭自碰撞；
- 用 Animation/Corrective Shape 掩盖极端姿势。

Teleport、低帧率和角色瞬移必须重置或重新初始化模拟，否则历史速度会把布料甩飞。

## 角色与服装穿模

穿模是服装与身体在动画过程中互相穿透的现象。它在两种情况下高发：服装没有独立骨骼动画、仅由身体骨骼驱动时；以及换装系统允许任意组合、无法为每对组合单独调整时。

治理手段按介入时机分为三类，通常需要组合使用。

### 离线裁剪

思路很直接：被衣服完全遮住的身体部分永远看不见，删掉即可。删掉之后自然不会穿出来。

判定方法是从服装的每个顶点沿法线反方向投射射线，命中身体时按距离阈值判断该处身体三角形是否需要剔除。生成的新网格缓存到本地，运行时直接使用。

遍历量很大，应当用作业系统或 Compute Shader 加速。有两个实现细节容易出错：碰撞体需要在同一帧之前建好，否则射线查询返回空结果；多层服装要按层级顺序处理，并防止服装触发自身或同链上其他网格的裁剪。

它的优势是零运行时成本，代价是需要为每种服装组合预先生成，且身体形态可变（捏脸、体型滑条）时预生成组合数会爆炸。

### 建模与权重约束

美术侧的措施成本最低：服装与身体之间保留足够间隙，服装的蒙皮权重尽量与对应身体部位一致。权重不一致是穿模的直接原因——同一块区域，身体按一组权重变形、服装按另一组变形，两者必然分离。

关节弯曲极限处是重灾区，肘部、膝盖、肩部需要单独检查。

### 运行时约束

物理模拟的布料需要正确配置碰撞体。身体碰撞体过于粗糙会让布料贴不紧，过于精细则模拟成本上升。

布料顶点数过多时，部分布料系统会拒绝工作或性能急剧下降。常见做法是用低模布料网格做模拟，再把结果传递到高模——这与毛发的 Guides 到 Strands 是同一思路。

### 验证

穿模必须用动画覆盖测试，静态姿势检查不出问题。做法是让角色遍历全部动画片段，在关键帧采样并自动检测穿透；换装系统则需要覆盖组合矩阵，至少覆盖每种服装与每种体型的配对。

## 毛发：Cards、Strands 与 Guides

Hair Cards 用少量带 Alpha 的面片表示发束。主要成本在 Overdraw、排序、阴影和各向异性材质。二级运动可用少量 Joint 或 Spring Chain。

Strand/Groom 直接表示大量发丝，通常先模拟少量 Guide Hair，再插值 Follower。还需要分 Cluster 做剔除、LOD 和渲染。

毛发模拟要处理长度、弯曲、碰撞和阻尼约束。近景可保留更多 Guide 与发丝，远景逐步降低密度，最终切到 Cards 或体积近似。几何 LOD、阴影 LOD 和材质 LOD 需要一起变化。

## 验证方法

- 测试低帧率、瞬移、极限动作和服装体型组合。
- 分别统计模拟、蒙皮、阴影、透明 overdraw。
- 逐级降低 guide 与物理网格密度，观察穿透和形态变化。
