# 毛发表示与模拟

近景需要发丝轮廓，远景却主要看到发束体积。毛发表示因此分成Cards、Strands与Guide代理，模拟密度、渲染密度和阴影预算分别变化。切换不能只减发丝数，还要保持运动与覆盖连续。

## 毛发：Cards、Strands 与 Guides

Hair Cards 用少量带 Alpha 的面片表示发束。主要成本在 Overdraw、排序、阴影和各向异性材质。二级运动可用少量 Joint 或 Spring Chain。

Strand/Groom 直接表示大量发丝，通常先模拟少量 Guide Hair，再插值 Follower。还需要分 Cluster 做剔除、LOD 和渲染。

毛发模拟要处理长度、弯曲、碰撞和阻尼约束。近景可保留更多 Guide 与发丝，远景逐步降低密度，最终切到 Cards 或体积近似。几何 LOD、阴影 LOD 和材质 LOD 需要一起变化。

## Guide到渲染发丝

机制伪代码中，Follower绑定到相邻Guide的相同弧长位置，权重来自离线映射。

```text
for sample in follower:
    position = sum(weight[g] * guide[g].SampleArcLength(sample.s))
    position += transportedFrame * bindOffset
```

## 验证方法

在甩头、瞬移、风和碰撞下检查长度及包围体。Guide减少后观察形态，Cards切换后核对覆盖、阴影和材质；高光主机制见风格化头发高光。
