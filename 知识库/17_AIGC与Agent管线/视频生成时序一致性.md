# 视频生成时序一致性

视频生成的时序一致性依赖表面对应、历史拒绝、模型条件与关键帧确认。固定随机种子支持相同任务重试，表面对应与遮挡由几何或估计光流提供；每份结果通过不可变清单连接，恢复按清单继续。
