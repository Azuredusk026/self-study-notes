# 视频生成时序一致性

逐帧生成每张图都清楚，播放时却可能闪烁。视频一致性需要追踪同一内容的运动，把可靠历史映射到当前，再为新显露区域重新生成。光流、潜变量与技术通道的坐标约定先对齐，才能谈时间滤波。

## 跨帧内容对应

### 逐帧差异

逐帧独立生成时，每帧虽然提示词相同，随机采样仍会改变：

- 轮廓和局部几何；
- 纹理、图案与文字；
- 光照和颜色；
- 遮挡关系；
- 小物件的出现/消失；
- 法线/深度等技术通道。

视频看起来会闪烁、纹理翻滚或形体漂移。只固定种子不能解决，因为每帧输入结构和去噪轨迹不同。

### 约束分层

可以按约束来源组合：

1. 固定输入几何/渲染序列；
2. 每帧深度/法线/姿态或边缘ControlNet；
3. 首帧/角色参考的 IP-Adapter；
4. 前一帧重投影后作为图生图输入；
5. 共享或相关噪声/潜变量；
6. 时序模块/视频扩散；
7. 输出后时间过滤与人工修复。

结构控制约束大形，参考条件帮助保持身份与风格，时序模型负责跨帧特征。单一方法通常不能同时解决全部问题。

### 光流重投影

已知前一帧图像 $I_{t-1}$，使用定义在当前像素上的反向光流 $B_{t\rightarrow t-1}$ 查询历史：

$$
\hat I_t(\mathbf{x})=I_{t-1}(\mathbf{x}+B_{t\rightarrow t-1}(\mathbf{x}))
$$

$\hat I_t$ 作为图生图初始图或一致性参考。前向光流定义在前帧坐标上，适合向当前帧散布；它不能直接在当前像素上取反就当作反向流，遮挡与空洞也需要单独处理。

光流在遮挡显露、快速运动、反射、透明和运动模糊区域不可靠。需要遮挡/置信度遮罩：可信区域保留历史，新出现区域重新生成。

反复重投影会累积拉伸和模糊。应定期用关键帧重新锚定，并让当前结构控制修正漂移。

### 潜变量与噪声一致性

相邻帧使用完全独立噪声会增加闪烁；使用相关噪声可让细节更连贯。但相机/物体运动后，同一潜变量像素不再对应同一表面。

更稳妥的是按运动信息或光流重投影潜变量或特征，并对遮挡显露注入新噪声。具体可行性取决于模型和节点实现，不能把像素光流无条件直接套到任意潜变量尺度。

固定潜变量也可能让纹理粘在屏幕空间。要检查细节是随对象、UV 还是相机移动。

### 关键帧与传播

先人工确认关键帧，再向前后传播：

1. 选镜头/动作变化明显的关键帧；
2. 固定角色、材质和风格参考；
3. 在关键帧间传播光流/条件；
4. 对遮挡显露和形体变化重新生成；
5. 检查接缝并局部重绘；
6. 保存关键帧与传播关系。

长镜头不应从第一帧一路单向传播，误差会积累。分段后在边界做双向传播或重叠混合。

## 技术通道的一致性

### 时序法线生成

单图法线估计器只能从外观猜几何，存在尺度、凹凸和光照歧义。逐帧预测会让法线方向和细节跳动。

先统一技术语义：

- 相机视空间还是世界空间；
- OpenGL/DirectX Y 方向；
- 值域 `[-1,1]` 如何编码到 `[0,1]`；
- 背景/无效遮罩；
- 是否单位化；
- 相机内外参；
- 是否需要切线空间法线。

仅对 RGB 法线做时间平均会缩短向量并跨表面污染。应解码到向量、按运动信息重投影、使用深度/遮罩/置信度拒绝，再归一化。

### 法线时间过滤

对当前法线 $\mathbf{n}_t$ 与重投影历史 $\mathbf{n}_h$，先检查：

- 深度/位置差；
- 对象或实例ID；
- 光流置信度；
- 法线夹角；
- 遮挡显露。

有效时可在向量空间归一化线性插值：

$$
\mathbf{n}'=\operatorname{normalize}((1-w)\mathbf{n}_t+w\mathbf{n}_h)
$$

稳定区域增大 $w$，运动边界和新出现区域减小 $w$。如果当前预测与几何深度梯度冲突，应降低历史或重新估计。

对离线序列可双向处理，利用前后帧；实时流程只能使用过去历史，延迟策略不同。

### 多通道一致性

生成 Base Color、法线、深度、遮罩等多个通道时，不能各自独立生成后再假设对齐。

优先让它们共享同一几何/结构源，或由一个主通道派生。若模型分别预测，必须验证：

- 边界和 对象ID 对齐；
- 法线与深度梯度一致；
- 遮罩没有时序跳变；
- 纹理细节不会在法线中产生假几何；
- 分辨率、裁剪 和镜头参数一致。

### 曝光与颜色稳定

结构稳定时，自动曝光、VAE 解码和每帧生成的色彩仍可能闪动。输入序列先固定色彩空间、曝光和色调映射；输出比较应在线性或明确的显示空间进行。

可以用稳定区域估计每帧亮度与颜色变换，但要排除大幅运动、闪光和真实灯光变化。把真实变化也强行归一化，会让效果失去能量。

颜色校正参数应平滑并限制变化速度。关键帧已批准的颜色可以作为锚点，镜头切换时重置历史，不把上一镜头统计带入下一镜头。

### 时序质量指标

单帧质量检查之外：

- 重投影误差：光流重投影后的颜色/特征差；
- 时序LPIPS或特征距离；
- 遮罩 IoU 和轮廓漂移；
- 法线角度误差/帧间差异；
- 闪烁频率与能量；
- 身份与风格嵌入稳定性；
- 人工检查关键动作、遮挡和镜头切换。

指标不能代替观看。过度平滑可获得较小帧差，却让细节拖影和失去响应。

## 历史法线过滤

伪代码中前帧法线先转到与当前同一空间，反向光流定义在当前像素上；通过几何与置信度检查后才混合。

```text
historyUv = uv + backwardFlow
if ValidHistory(historyUv, depth, mask, confidence):
    historyNormal = TransformPreviousNormalToCurrentSpace(load(historyUv))
    outputNormal = normalize((1-weight)*currentNormal + weight*historyNormal)
else: outputNormal = currentNormal
```

## 坐标换算与遮挡拒绝

反向光流若以原图像素为单位，转换到UV需除以原图宽高。潜变量宽高分别缩小s倍时，对应位移也缩小s倍；直接把像素位移加到latent索引会把运动放大。裁剪、缩放与填充还会改变坐标原点，需把整条预处理变换应用到位置和位移。

法线属于方向。若前帧与当前帧都保存视空间法线，先用前帧视图旋转的逆变换到世界，再用当前视图旋转变到当前视空间。这一步只消除相机坐标变化；若对应表面随刚体旋转，还需用当前物体旋转乘以前帧物体旋转的逆，将历史世界法线输送到当前姿态。蒙皮变形需要对应的形变信息，缺少时按法线夹角等条件拒绝历史。只要相机旋转，即使物体静止，两帧视空间法线数值也会变化；直接相加会把坐标变化误当几何变化。

遮挡判断同时检查重投影位置是否在图内、对应深度是否一致、对象身份是否相同。当前显露背景在历史中被前景挡住时，没有可用历史，重新生成才是正确分支。评价时把有效历史区域的误差与拒绝比例一起报告，否则把所有像素拒绝也可能得到很小的“历史误差”。

## 验证方法

静态、平移、遮挡显露与镜头切换分别检查，保存光流、拒绝原因与每帧条件。向量平均接近零时回退当前，不能把低帧差当作无拖影。
