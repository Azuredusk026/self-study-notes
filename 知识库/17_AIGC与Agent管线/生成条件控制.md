# 生成条件控制

文字能描述人物，却很难精确固定每个关节和轮廓。结构控制把Depth、Pose或Edge直接送入匹配分支，参考条件提供外观特征。控制权重不能修复错误预处理，输入语义要先核对。

## ControlNet

ControlNet 为预训练扩散模型增加可训练控制分支，把 Edge、Depth、Normal、Pose、Segmentation 等结构信号注入去噪网络。

常见工作流：

```text
Reference Image
 -> Preprocessor
 -> Control Map
 -> Matching ControlNet
 -> Denoising Network
```

Preprocessor 输出必须与 ControlNet 训练类型匹配。Canny Map 接到 Depth Control 模型，节点仍可能运行，但条件语义错误。

控制参数包括 Weight、Start/End Step 和 Resolution。强度过高会把预处理噪声和错误结构一起锁死；过低则约束不足。

Normal/Depth 预处理本身可能有尺度、坐标和遮挡错误。控制分支会把输入偏差带入生成，模型也可能忽略部分约束。先显示预处理图，确认坐标、范围和边界，再调整控制强度，才能区分输入错误与模型失配。

## IP-Adapter

IP-Adapter 把参考图编码为 Image Embedding，通过额外 Attention/Condition 影响生成。它适合传递角色、对象、构图或风格语义。

与 ControlNet 的典型分工：

- ControlNet 偏空间结构；
- IP-Adapter 偏参考图语义/外观；
- Text Prompt 提供可编辑意图；
- Mask 决定影响区域。

多种条件叠加会竞争。应逐一启用并记录 Weight，不要直接把 Text、多个 ControlNet、IP-Adapter 和 LoRA 全开后凭感觉调参。

参考图来源和使用授权必须进入记录。技术上可提取特征不等于项目有权使用。

## 条件接口

管线伪代码输入图像与控制类型，预处理结果必须与训练分支匹配。

```text
control = Preprocess(reference, expectedType)
validate resolution, range, axes and invalidMask
condition = AttachControl(control, weight, activeSteps)
sample matching base model with condition
```
