# 生成条件控制

文字能描述人物，却很难精确固定每个关节和轮廓。结构控制把深度、姿态或边缘图直接送入匹配分支，参考条件提供外观特征。控制权重不能修复错误预处理，输入语义要先核对。

## ControlNet

ControlNet 为预训练扩散模型增加可训练控制分支，把边缘图、深度、法线、姿态、分割图 等结构信号注入去噪网络。

常见工作流：

```text
Reference Image
 -> Preprocessor
 -> Control Map
 -> Matching ControlNet
 -> Denoising Network
```

预处理器输出必须与 ControlNet 训练类型匹配。Canny Map 接到深度控制模型，节点仍可能运行，但条件语义错误。

控制参数包括权重、起始与结束步数和分辨率。强度过高会把预处理噪声和错误结构一起锁死；过低则约束不足。

法线/深度预处理本身可能有尺度、坐标和遮挡错误。控制分支会把输入偏差带入生成，模型也可能忽略部分约束。先显示预处理图，确认坐标、范围和边界，再调整控制强度，才能区分输入错误与模型失配。

## IP-Adapter

IP-Adapter 把参考图编码为图像嵌入，通过额外注意力分支或条件影响生成。它适合传递角色、对象、构图或风格语义。

与 ControlNet 的典型分工：

- ControlNet 偏空间结构；
- IP-Adapter 偏参考图语义/外观；
- 文本提示词提供可编辑意图；
- 遮罩决定影响区域。

多种条件叠加会竞争。应逐一启用并记录权重，不要直接把 文本、多个 ControlNet、IP-Adapter 和 LoRA 全开后凭感觉调参。

参考图来源和使用授权必须进入记录。技术上可提取特征不等于项目有权使用。

## 条件接口

管线伪代码输入图像与控制类型，预处理结果必须与训练分支匹配。

```text
control = Preprocess(reference, expectedType)
validate resolution, range, axes and invalidMask
condition = AttachControl(control, weight, activeSteps)
sample matching base model with condition
```

## 控制分支与注意力

ControlNet复制可训练分支，并通过零初始化卷积把残差送回冻结网络。训练开始时残差为零，原网络输出得到保留；随着控制分支与零卷积学习，空间条件逐步影响各层特征。这条残差路径解释了为何“边缘图”能约束空间布局，也解释了它必须匹配基础网络的层级与通道。

IP-Adapter把图像特征与文本特征放在独立交叉注意力分支里。以相同查询Q分别对文本和图像键值计算注意力，再按强度相加，概念形式为 `Attention(Q,Ktext,Vtext)+w*Attention(Q,Kimage,Vimage)`。文本负责语义编辑，图像分支提供参考特征，两者仍可能对服装、构图或风格提出冲突要求。

验证时建立三组相同种子的结果：只用文本、文本加结构图、再加参考图。先比较关节或边界是否跟随结构，再比较身份与外观；如果结构图本身镜像，增大权重只会更稳定地复制错误。控制窗口按实际调度器的步或噪声尺度解释，不能跨工作流假设相同比例必然产生相同效果。
