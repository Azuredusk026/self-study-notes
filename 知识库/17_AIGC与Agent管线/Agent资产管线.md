# Agent资产管线

Agent资产管线把需求解析、资产选择、场景执行、技术验证与审核发布连接成可恢复任务。模型提出语义候选，工具提交明确状态变化，验证器读取实际产物；任务记录保存它们共享的身份、版本与回执。

- [[17_AIGC与Agent管线/资产任务编排与发布]]：资产任务如何连接规划、验证、审核与不可变版本发布？
- [[17_AIGC与Agent管线/资产布局的几何验证]]：资产布局如何在统一空间中验证几何与交互可达性？
- [[17_AIGC与Agent管线/场景工具的条件执行]]：场景工具如何在并发、超时和接管下实现条件执行与恢复？
- [[17_AIGC与Agent管线/场景补偿的版本承接]]：取消场景操作如何按局部字段和持久回执承接版本？
- [[17_AIGC与Agent管线/补偿隔离与冲突接管]]：补偿中间态如何隔离，冲突与残留如何接管？

任务编排定义各阶段消费的记录，几何验证确定布局门禁，条件执行保护读取依赖，补偿版本承接处理逆序恢复，隔离与冲突接管决定取消残留的去向。正式发布消费绑定同一快照的完整报告与批准记录。
