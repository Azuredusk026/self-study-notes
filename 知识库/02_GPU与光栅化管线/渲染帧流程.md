# 渲染帧流程

CPU 准备逻辑与资源，GPU 执行队列中的命令，显示系统再呈现图像。这些工作可以跨帧重叠，所以帧率、排队和输入延迟要沿整条时间线理解。

## 阅读路线

先掌握空间变换与 GPU 执行，再沿命令记录、几何覆盖、附件写入和显示呈现阅读。各阶段的开始与结束需要结合队列依赖理解；CPU 记录完一帧后，GPU 可能仍在处理此前提交的工作。

诊断卡顿时，从帧时间线定位等待，再回到对应环节。Present 附近的等待可能涉及限帧、显示同步或 GPU 积压，具体判断见显示呈现与帧瓶颈诊断。
