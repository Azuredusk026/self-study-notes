# 抗锯齿与时域重建

锯齿不是只发生在三角形边缘。几何覆盖、纹理、高光、阴影和透明测试都会产生高频信号。不同抗锯齿方法处理的信息不同。

时域抗锯齿（Temporal Antialiasing，TAA）通过跨帧复用样本近似更密集的空间采样。它要解决的仍是空间锯齿，手段是把每像素多个采样点分摊到连续多帧，用时间换取采样数。

样本累积解释了静止画面的收敛，也引出最困难的问题：上一帧的颜色还能代表当前像素吗？运动、遮挡和着色变化都会改变答案，后续就沿累积与校验两条线展开。

## 空间采样方案

### 超采样（SSAA）

用更高分辨率渲染，再过滤到目标分辨率。它同时改善几何、纹理和 Shader 锯齿，接近最直接的参考方案。

更高分辨率通常增加片元、附件和带宽成本，几何处理不一定同比增加。它常用于对照图；是否全程采用取决于预算。

### MSAA

MSAA 在每个像素保存多个 Coverage/Depth 样本，但通常只执行一次 Pixel Shader，再把结果写到覆盖样本。

它擅长处理三角形边缘，因为同一像素内多个样本可以表示部分覆盖。

它不能自动解决：

- Shader 内部的程序化硬边；
- 高频法线和高光；
- 纹理缩小；
- 没有使用 Alpha-to-Coverage 的 Alpha Test 边缘；
- 时域闪烁。

Deferred Rendering 使用多个 GBuffer 时，MSAA 会增加存储和解析复杂度，因此很多引擎改用时域方案。

#### Sample Frequency 和 Resolve

MSAA 的 Coverage 和 Depth 按样本保存，Pixel Shader 默认可以按像素频率运行。三角形边缘的多个样本可能属于不同 Primitive，此时实现会根据覆盖拆分调用，或让 Shader 按样本频率执行。`centroid` 插值可避免插值位置落在当前 Primitive 覆盖之外。

Resolve 把多样本颜色转换成单样本颜色。普通线性颜色通常做算术平均：

```hlsl
Texture2DMS<float4, 4> MsaaColor : register(t0);

float4 Resolve4x(uint2 pixel)
{
    float4 sum = 0.0;
    [unroll]
    for (uint sampleIndex = 0; sampleIndex < 4; ++sampleIndex)
        sum += MsaaColor.Load(pixel, sampleIndex);
    return sum * 0.25;
}
```

实际 API 通常提供硬件 Resolve。手写代码适合需要自定义权重或检查样本值的场景。输入应该是线性颜色；在 sRGB 编码值上直接平均会得到错误亮度。

Depth、Stencil、Normal、Material ID 等数据没有统一的“平均”含义。Depth 可能按最近样本、最远样本或保留多样本形式处理，取决于反向 Z 和后续用途。Deferred 在几何边缘可能需要逐样本光照，或通过边缘检测只对复杂像素走特殊路径。

### FXAA

FXAA 是单帧后处理。它根据亮度或颜色变化检测边缘，再沿边缘方向平滑。

一种可推演的单帧边缘过滤先读取中心与上下左右的亮度。若邻域最大值与最小值之差小于阈值，就保留中心；差异较大时，比较横纵方向的变化，沿估计的边缘切向搜索两端，再在边缘法向选择偏移后的颜色。搜索范围和阈值限制成本，偏移试图把阶梯边界变成连续覆盖。

例如水平黑白分界在上侧为1、下侧为0，而同一行邻居近似相等，亮度变化主要沿竖直方向，边缘切向便沿水平方向。若把方向认反而沿竖直搜索，搜索会越过边界并模糊本不相关的表面。完整FXAA还包含子像素与边缘端点启发式，本段只展开这类图像过滤的决策链，不作为对应版本源码实现。

它只有最终颜色，无法区分一条真实几何边与文字笔画；平滑同样的高对比形状时，文字也可能变软。它也没有上一帧信息，不能判定某个闪烁纹素在时间上应如何平均。性能取决于邻域读取、搜索长度与实现，不能只凭名称给固定耗时。

## 时域抗锯齿

一条完整的 TAA 由两件事构成，后续所有技术都归属于其中之一：

```text
样本累积          历史校验
  ├ 抖动采样        ├ 拒绝：判定失效则丢弃
  ├ 重投影          └ 矫正：拉回到合理范围
  └ 混合权重
```

每帧的数据流是：抖动投影矩阵渲染出新样本，用运动向量把上一帧输出重投影到当前位置，校验这份历史是否可信，再按权重与新样本混合，结果既是本帧输出也是下一帧的历史。

### 抖动

每帧给投影矩阵加一个亚像素偏移，使采样点在像素内均匀覆盖。

#### 写入投影矩阵

先明确约定：抖动 $j$ 以像素为单位，屏幕宽高为 $(W,H)$，对应NDC偏移为 $(2j_x/W,2j_y/H)$。屏幕Y向下而NDC向上时还需反转Y符号。要让透视除法后的坐标增加该偏移，应在齐次裁剪坐标上加偏移乘w：

```hlsl
// jitterNdc已按屏幕原点和投影约定转换；positionCS为未抖动位置
positionCS.xy += jitterNdc * positionCS.w;
```

将这一操作合并进投影矩阵时，矩阵元素的索引和符号由行列向量及视空间前向决定。验证方式是冻结场景，给出正0.5像素的抖动，确认所有深度处的图像都沿约定方向平移0.5像素。

#### 序列的选择

物体可能在任意时刻出现或被遮挡揭露，因此一个像素的累积可以从序列的任意位置开始。理想序列需要满足：**任意长度的任意子序列都大致均匀分布**。

低差异序列能改善连续样本的覆盖，Halton(2,3) 是常用选择，但不保证任意长度、任意起点的子序列都均匀。短序列仍需检查分布与运动相关性。序列长度按目标质量取，常见 8 到 16 个样本。

运动会打乱精心设计的采样分布：短周期序列配合特定运动速度时，多帧的采样点可能在世界空间聚成一簇，导致结果偏移。随机化抖动模式可以打破这种规律性。

#### 纹理采样偏置

纹理本身已经过 Mipmap 过滤，再经 TAA 平均会过度模糊。可试验负Mipmap偏置以保留更高频细节。若将独立有效样本理想化为二维均匀分布，线性采样间距约缩小到原来的 $1/\sqrt{N_{eff}}$，可得到偏置的启发值：

$$
bias=-\tfrac{1}{2}\log_2 N_{eff}
$$

有效采样数为 4 时偏置为 $-1.0$。实践中常取比理论值保守一些的数值，因为过度偏置会损害时域稳定性与纹理缓存效率。这一点在时域超分下尤其重要。

## 历史累积与重投影

### 样本累积

存下每个像素的全部历史样本不现实。主流做法是把累积结果平均成单一颜色，它既是当前帧输出，也是下一帧的历史输入：

$$
f_n(p)=\alpha\cdot s_n(p)+(1-\alpha)\cdot f_{n-1}(\pi(p))
$$

$s_n$ 是本帧新样本，$\pi(\cdot)$ 是重投影算子，$\alpha$ 是混合系数。

#### 固定系数等价于指数平滑

展开递推式可以看到历史的真实构成：

$$
f_n(p)=\alpha\left(s_n+(1-\alpha)s_{n-1}+(1-\alpha)^2s_{n-2}+\cdots\right)
$$

越旧的样本权重越低。这在多数情况下是合意的——旧样本更可能已经失效。

但从方差削减的角度看，**这是次优的**：对独立、同分布且等方差的静态样本，等权平均使方差最小。时域样本有相关性、运动和可信度差异时，最佳权重需要考虑这些条件。固定 $\alpha$ 在样本数很少和很多两端都会损失质量。

#### 等效采样数

固定 $\alpha$ 累积 $N$ 帧，相当于多少次等权重超采样？这个换算直接决定了参数选择：

| 累积帧数 | 等效采样数（$\alpha=0.1$） |
|---|---|
| 5 | 约 2.2 |
| 10 | 约 5.1 |
| 15 | 约 9.8 |
| 稳态 | 约 19 |

表中用首帧样本初始化历史；第N帧最旧样本的权重为 $(1-\alpha)^{N-1}$，其余权重为 $\alpha(1-\alpha)^k$。在独立等方差假设下，$N_{eff}=1/\sum_iw_i^2$，稳态为 $(2-\alpha)/\alpha=19$。它衡量方差，不能直接等同于19倍MSAA的覆盖或运动质量。同时也说明收敛需要时间，相机切换后的前几帧质量明显偏低。

#### 等权重方案

在静态、独立等方差样本的前提下，可以在历史缓冲的 Alpha 通道存逐像素累积样本数 $N_t(p)$：像素刷新时置1，此后每帧递增，取 $\alpha=1/N_t(p)$。未发生历史变形或拒绝时，这让历史样本保持相同权重。

代价是多占一个存储通道。它适合需要在遮挡揭露后快速收敛的场景，尤其目标帧率较低时。

注意历史被拒绝或矫正后，$N_t(p)$ 必须同步更新以匹配实际的 $\alpha$，否则计数与真实累积状态脱节。

#### $\alpha$ 的下界

$\alpha$ 过小时结果容易受重采样误差与时域滞后影响。通常给它设一个下界，保证历史有最低限度的刷新率。下界可以随运动速度提高——运动越快，重采样误差累积越快，越需要更多新数据。

### 在管线中的位置

直接平均HDR颜色时需要处理高亮离群值：高动态范围下，少数极亮样本会主导平均值，边缘梯度被破坏。

解决办法是在 TAA 前后各做一次色调映射与其逆变换：

```text
HDR 渲染 → 可逆 Tonemap → TAA → 逆 Tonemap → HDR 后处理 → 最终 Tonemap
```

中间这次使用简单可逆的算子即可，例如非负标量 Reinhard 形式 $x/(1+x)$，逆变换为 $y/(1-y)$，它只作为最终色调映射的代理。

#### 亮度自适应权重

另一条路径是在混合时按亮度加权，避免色调映射导致的去饱和：

$$
w(c)=\frac{1}{1+L(c)}
$$

$L(c)$ 是颜色的亮度通道，$w$ 作为双边权重参与混合。它能抑制极高能量像素形成的亮点噪声（firefly），也常用于稳定泛光效果。

### 重投影

#### 运动向量

运动向量记录表面点在屏幕空间的投影位移。先用上一帧与当前帧的变换得到同一表面点的裁剪空间位置，分别除以各自的w，再转换为相同原点约定的屏幕UV。本文定义 $v=uv_{current}-uv_{previous}$，消费时用 $uv_{previous}=uv_{current}-v$；直接相减两个裁剪空间位置会把透视尺度混入位移。

例如两帧裁剪坐标x均为2，当前w为4、上一帧w为2，对应NDC横坐标为0.5和1，因此UV横向速度为-0.25，而不是0。这里要求两帧位置都能有效投影；上一帧位于相机后方或历史UV越界时应拒绝历史。

精度要求较高，常用两通道 16 位浮点格式存储。一种清晰的约定是运动向量排除投影抖动，由重投影阶段单独补偿前后帧抖动差。其他实现也能把抖动编码进向量，但生产与消费必须使用同一约定。

骨骼动画需要上一帧的骨骼姿态；UV动画若能建立明确的表面流动对应关系，可另外输出运动；一般贴图动画不能仅把UV偏移直接当成屏幕位移；平面反射需要推导反射矩阵对应的运动关系。

为节省带宽，部分引擎只为动态物体显式写运动向量，并用模板标记；未标记像素在 TAA 阶段用深度实时反算：

$$
p_{n-1}=M_{n-1}M_n^{-1}p_n
$$

$p_n$ 是当前帧像素的裁剪空间齐次坐标，$M$ 是各帧的视图投影矩阵，结果经透视除法得到。

复杂贴图动画、粒子、烟雾、水流和多层透明未必具有可由单个向量表达的对应关系。例如一个像素混合了两个反向运动的透明表面，任取一个向量都会错配另一层。这类内容可采用响应遮罩、分层历史或更高刷新权重，误差是否可接受应按具体运动和覆盖验证。

#### 采样邻域最近深度

直接用当前像素的运动向量，在遮挡边界处会取到错误的历史位置。改用邻域中**离相机最近**的那个点的运动向量，可以让前景的运动向量“覆盖”边界像素，减弱遮挡变化造成的错误。

```hlsl
float2 GetClosestFragment(float2 uv)
{
    float2 k = _CameraDepthTexture_TexelSize.xy;
    float3 result = float3(0.0, 0.0, SampleDepth(uv));

    // 比较四个对角邻居，保留离相机最近的偏移
    result = lerp(result, float3(-1, -1, SampleDepth(uv - k)),
                  CompareDepth(SampleDepth(uv - k), result.z));
    result = lerp(result, float3( 1, -1, SampleDepth(uv + float2(k.x, -k.y))),
                  CompareDepth(SampleDepth(uv + float2(k.x, -k.y)), result.z));
    result = lerp(result, float3(-1,  1, SampleDepth(uv + float2(-k.x, k.y))),
                  CompareDepth(SampleDepth(uv + float2(-k.x, k.y)), result.z));
    result = lerp(result, float3( 1,  1, SampleDepth(uv + k)),
                  CompareDepth(SampleDepth(uv + k), result.z));
    return uv + result.xy * k;
}
```

该片段用选择运算表达更新；编译器如何生成分支或谓词需看输出，不能由`lerp`写法保证性能。深度比较方向取决于是否启用反向 Z，必须按约定推导而非照抄符号。取五点或九点邻域是质量与成本的权衡。

另一种做法是对前景物体做小范围膨胀（常用四抽样窗口），让边界像素随前景一起重投影。因为运动向量本身无法被抗锯齿，不做处理时运动物体的平滑边缘会重新出现锯齿。

#### 重采样滤波

重投影位置通常落在像素之间，需要重采样。双线性采样最廉价，但保留高频的能力差，而且**误差每帧累积**——历史反复经过重采样，很快就糊得明显。

改进方向是使用更高阶的重采样核：

- **Catmull-Rom** 三次插值，可利用双线性采样合并相邻正权项；完整二维核和缩减为五次采样的近似核应分别比较，后者需要说明删减的贡献及归一化方式；
- **前后误差补偿（BFECC）** 通过反向重采样估计误差并修正；
- **带预滤波的广义重采样**可在其信号和边界假设下减少反复重采样误差，代价包括额外滤波与存储。

反复重采样会放大滤波器差异。比较时固定图像、位移和边界规则，分别测量模糊与振铃，不能把某个重采样次数下的结果当作全部内容的保证。每帧混入新样本可以部分缓解累积模糊，但不能消除。

### 历史校验

重投影得到的历史不能无条件使用：它可能因遮挡变化而**无效**，也可能因光照或着色变化而**陈旧**。校验手段分两类。

#### 拒绝

检测到问题就丢弃历史，把 $\alpha$ 置 1，或限制在某个下界做软刷新。

判据来自两类数据：

**几何数据**（深度、法线、对象标识、运动向量）适合识别遮挡变化。将当前表面重投影到上一帧后，比较其预测的上一帧深度与历史深度纹理，差异超过容差则拒绝。两者要处于同一坐标与深度约定，不能直接比较当前帧和上一帧的原始设备深度。

几何判据只能反映一部分着色输入：表面深度与法线不变时，光照、阴影和反射仍可能变化。对象标识不能做算术平均，深度跨表面插值也会生成不存在的中间表面；法线等连续量则需要与其含义匹配的过滤和归一化。判据在边缘的不连续还可能重新引入锯齿，因此通常需要结合颜色校验。

**颜色数据**更直接地反映历史是否仍然一致，既能发现着色变化，也能发现重采样误差与错误运动向量。但当前帧样本本身带锯齿（否则也不需要抗锯齿），直接比较会得到有偏且不稳定的误差估计，通常需要先做空间滤波。

#### 矫正

拒绝历史等于重置该像素的积分过程，会加剧时域伪影。矫正的思路是把历史拉回到与当前帧一致的范围内，而非直接丢弃。

核心假设是：**当前帧邻域的样本涵盖了该像素应有的颜色范围**。取 3×3 或更大邻域的颜色，它们在颜色空间中的凸包代表合理范围。历史落在凸包内则可信；落在外面，则把“历史到当前样本”的连线与凸包求交，交点就是最接近历史且仍然合理的估计。

逐像素求凸包太昂贵，实践中用轴对齐包围盒近似，并有两种处理方式：

**Clamp** 直接把历史各分量钳制到包围盒内。结果可能落在盒面、边或角上；各轴独立移动，通常不保持原来的颜色变化方向。

**Clip** 沿盒心到历史的方向缩短向量，使结果落在盒边。它保留相对于盒心的方向；对最终画质的影响还取决于邻域是否代表真实颜色：

```hlsl
float3 center = (AABBMin + AABBMax) * 0.5;
float3 extent = (AABBMax - AABBMin) * 0.5;
float3 delta = History - center;
float3 ratio = abs(delta) / max(extent, 1e-6);
float scale = max(1.0, max(ratio.x, max(ratio.y, ratio.z)));
float3 Result = clamp(center + delta / scale, AABBMin, AABBMax);
```

每轴偏离量除以该轴半宽得到超出比例。最大比例小于等于1时历史在盒内；大于1时统一缩短三个分量。零宽轴用数值下界防止除零，最终clamp保证落在原盒内，因此退化盒可能轻微改变方向。输入要求每轴Min不大于Max。

#### 颜色空间与离群值

包围盒可以在 YCoCg 空间中计算。它把色度与亮度解耦，而局部对比通常由亮度主导，因此得到的包围盒比 RGB 下更紧，矫正更有效。

极暗或极亮的离群样本会撑大包围盒，让本应被矫正的历史通过检测。**方差裁剪**用邻域的均值与标准差确定范围，而非最值：

$$
C_{min}=\mu-\gamma\sigma,\qquad C_{max}=\mu+\gamma\sigma
$$

$\gamma$ 通常取 0.75 到 1.25。均值和方差仍受离群值影响，这是一种可调的范围估计。可再与邻域最值盒相交，避免统计盒扩张过大。

#### 混合系数自适应

静态场景可以用较小的固定系数。按运动幅度提高系数是一种加快刷新的启发式，并不意味着匀速平移的历史必然失效。下列HLSL片段假定motion是每帧UV位移，0.05与100为需要按分辨率和内容调整的参数：

```hlsl
float blendFactor = saturate(0.05 + length(motion) * 100.0);
return lerp(historyColor, currentColor, blendFactor);
```

另一个有用的启发式是：历史接近被裁剪时适度降低 $\alpha$，让裁剪发生后的变化更平缓，减少突兀跳变。

### 一个像素的历史决策

设当前UV=(0.6,0.5)、运动向量按本页约定为(0.1,0)，历史读取位置为(0.5,0.5)。预测上一帧表面正线性深度为5米，历史记录为2米，容差0.1米时应拒绝：当前表面之前被前景遮住，历史颜色来自另一个表面。此时令alpha=1，输出当前样本，累积计数重置。

若历史深度也为5米、几何验证通过，当前邻域亮度范围[0.2,0.8]，历史为1.2，标量裁剪后为0.8。当前样本0.4、alpha=0.1时，结果为`0.1*0.4+0.9*0.8=0.76`。如果邻域欠采样而完全漏掉真实亮线，范围可能缩到[0.2,0.4]，同样裁剪会删除正确历史。一次深度验证和一次颜色限制各自回答不同问题；提高刷新率可以缩短残影，也会减少历史降噪收益。

## 伪影的成因

TAA 的各类伪影可以归到同一个根源：**欠采样的输入无法可靠判断历史是否有效**。判断的两类错误导向两组相反的伪影。

| 判断错误 | 后果 |
|---|---|
| 假阳性（有效历史被判为无效） | 模糊、闪烁 |
| 假阴性（无效历史被判为有效） | 鬼影、时域滞后 |

因此**抑制鬼影与抑制闪烁是一对矛盾目标**，任何校验算法都在这两者间取舍。理解这一点，就不会期待某个参数能同时解决两者。

### 模糊

两个来源。其一是前述的重采样误差累积。其二是历史矫正本身：

矫正假设当前帧邻域涵盖了该像素的颜色范围，但内容高度精细时这个假设会失效。一条亚像素宽的细线可能在某些帧的采样中**完全缺失**，此时包围盒不包含线的颜色，历史中累积的细节被裁掉。表现为茂密树枝、细密栏杆在收敛后反而丢失。

限制历史有助于抑制鬼影，也可能删除真实细节。后续锐化可提高剩余细节的局部对比，却不能恢复已经丢失的样本。锐化还可能产生过冲，需要限幅并检查色域和振铃。

### 鬼影

常见于运动物体造成的遮挡揭露区域：失效历史未被完全清除，表现为运动物体拖出一个副本。

根因在于矫正在**高对比边界处失效**：当前帧样本包含密集的高对比边缘时，颜色包围盒被撑得很大，不再能代表该像素真实的颜色范围，失效历史因此顺利通过检测。角色跑过草地时在草上拖出残影是典型案例。

错误的运动向量同样致病，常见于透明、粒子与反射。

对策是给容易出问题的材质打上响应标记，写入模板，TAA 阶段据此提高该区域的 $\alpha$ 加快刷新。平滑边缘处需要膨胀模板，因为边缘上约半数像素可能未被标记。

### 闪烁

TAA 本应减少闪烁，但历史矫正可能反而制造它。

当输入存在低频摩尔纹时，某些像素的邻域色域**每帧完全改变**。历史每帧都被裁剪或钳制到当前样本值，累积过程实际上被停用——TAA 退化成了逐帧直通。关闭或放宽矫正能消除闪烁，但会暴露鬼影与滞后。

### 欠采样

累积样本数低的区域仍有可见锯齿，典型位置是相机切换后的前几帧、遮挡刚揭露的区域、着色剧变的区域。表现是过锐且带锯齿，与收敛后的画面观感不一致。

缓解办法是提高这些区域的空间复用：对新样本施加低通滤波，或叠加一层空间抗锯齿方法处理当前帧的原始样本。

## 高频细节的稳定性

TAA 变清晰的前提是：同一个表面点在连续多帧中被不同的亚像素位置采样，这些样本可以合并成一次超采样。前提成立时，静止画面会随帧数累积越来越清晰。

头发、细密织物、远处栅栏这类内容会打破这个前提，原因有三层，各自需要不同的应对。

**一、亚像素几何的样本不指向同一表面**。一根发丝宽度可能小于一个像素。抖动后的采样位置可能命中发丝、也可能命中背后的皮肤或背景。像素覆盖积分本来就可能包含前景与背景，平均不同表面的当前覆盖样本可以是正确的抗锯齿。TAA 的困难是历史重投影可能把不对应同一时刻覆盖的样本当成有效历史，再与当前结果混合。细发丝缺少稳定深度和运动信息时尤其明显。

**二、高光随视角剧烈变化**。头发的各向异性高光对视角与切线方向极其敏感，相机或角色轻微移动，同一位置的高光强度就大幅跳变。历史颜色与当前颜色差异巨大，Neighborhood Clamp 会频繁拒绝历史——要么保留历史导致拖影，要么拒绝历史导致闪烁。

**三、Motion Vector 不可靠**。发片薄、遮挡关系复杂，且常有 Alpha Test。被 Clip 掉的片元不写运动向量，导致该像素的历史查找位置错误。

理解这三层才能选对手段：第一层是采样问题，第二层是信号问题，第三层是数据问题。

### 应对方向

**保证数据正确**。先确认头发正确输出了运动向量，包括骨骼动画与物理模拟导致的位移。先用静止相机和运动角色对照向量，再观察历史查找是否跟随对应表面。

**降低信号本身的高频程度**。在着色阶段就让高光不那么跳：限制高光强度上限、对高光做适度的时域平滑、或在切线扰动上减少高频噪声。源头信号稳定了，时域累积自然稳定。

**分区域调整 TAA 参数**。用材质分类标记区分头发区域，对该区域采用更激进的历史拒绝（减少拖影，接受一些闪烁）或更保守的混合权重，而不是全屏统一参数。这需要 GBuffer 中有可用的分类信息。

**几何层面减少亚像素细节**。距离较远时切换到更粗的发片或使用预积分的高光，从根本上避免亚像素几何。这与 LOD 是同一思路。

**用锐化补偿**。TAA 之后施加一道轻度锐化，恢复部分被平滑掉的细节。它不解决成因，只补偿观感，且过度锐化会放大闪烁与边缘振铃。

### 分辨率与着色率

提高输入分辨率可增加亚像素几何覆盖的观测，但仍需正确运动向量及历史校验。降低着色率会减少着色样本，适合信号平缓的区域；高频头发区域是否可用，应按覆盖、运动和高光分别评估。参数选择从缺失的是几何样本、着色信息还是可靠历史对应关系开始。

## 仅用重投影的简化方案

省去运动向量，只靠深度反算重投影。物体快速运动时结果不正确，但成本低得多。

静态场景中，深度重投影可复用屏幕空间环境光遮蔽等效果的历史。反射命中点、体积积分区间与当前可见表面可能没有相同运动，需另外设计重投影及拒绝条件；相机矩阵本身不能解释这些信号的移动。

随机化效果可以借用历史累积摊薄采样，但必须分别定义被积信号与历史对应。例如AO通常跟随当前表面，反射却还依赖反射命中物与视角。只给效果随机样本而复用表面运动，不足以保证积分有效；无法建立对应关系的区域应提高刷新或拒绝历史。

## 时域超采样

把每像素采样率降到一个以下，累积到更高分辨率的缓冲，TAA 就成了超分方案。

由于输入样本与输出像素不再一一对应，需要先按重建核把输入样本升采到输出分辨率，再按**质量置信度**决定混合强度：

$$
f_n(p)=\alpha\beta(p)\bar{s}_n(p)+(1-\alpha\beta(p))f_{n-1}(\pi(p))
$$

$\beta(p)\in[0,1]$ 表达该输出像素本帧获得的样本质量。靠近实际采样点的像素置信度高，仅由远处样本插值而来的置信度低。合理的抖动模式下，每个输出像素每隔几帧就能获得一次高质量样本。

以两倍超分、盒式核为例：输入与输出是 1:4 映射，每帧 2×2 输出块中只有一个像素的 $\beta$ 为 1 并被更新，其余三个保持历史不变。这个框架支持任意超分倍率。

超分下输入更稀疏，历史校验比常规 TAA 更困难，各类伪影也更明显。

## 成本特性

TAA的重建通道通常按输出像素执行，分辨率、滤波核、历史格式及拒绝路径影响成本。运动向量生成、响应标记等前置工作还与场景有关，不能只用全屏通道时间代表集成成本。

GPU 时间需注明设备、输出分辨率、历史格式、重建核和测量方法。分辨率提高会增加采样与写入量，具体耗时以目标平台计时为准。

MSAA成本随样本数、附件布局、着色频率和几何复杂度变化。分块架构可以把部分多样本附件保留在片上，但片上容量、解析与溢出也有代价，应在相同画质目标下与时域方案比较。

时域超分还可能带来额外开销：它同时承担抗锯齿职责，必须置于部分后处理之前，导致这些后处理要在升采后的分辨率上执行。

## 与引擎的耦合

TAA 原理不复杂，但与渲染管线关系极深。每一项渲染功能都需要考虑它的影响：材质要提供运动向量，透明与粒子需要响应遮罩，后处理顺序要重新安排，随机化效果要配合它的积分特性。

这是集成 TAA 的主要成本，也是不同引擎实现细节差异很大的原因。

## 方案选择

| 方法 | 处理的锯齿 | 主要代价 | 适用 |
|---|---|---|---|
| SSAA | 增加空间采样可处理的来源 | 片元、附件和采样量增长 | 离线参考、截图 |
| MSAA | 几何边缘 | 随几何与深度复杂度变化 | 前向渲染、移动端 |
| FXAA | 图像上的边缘 | 极低 | 低端兜底、叠加使用 |
| TAA | 能建立可靠历史对应的多类信号 | 重建及历史数据成本 | 延迟渲染、桌面与主机 |

多重采样GBuffer增加附件与逐样本光照的组织成本，时域方案则增加运动向量、历史和重建成本。前向或延迟路径只给出候选条件，实际选型按目标设备、内容与稳定性要求比较。

这些方法并不互斥。常见组合是以时域方案为主，用空间方法处理它尚未收敛的区域。

## 验证方法

- 用高对比斜边、细线与棋盘格纹理做基准，逐项开关各抗锯齿方法，确认每项解决的锯齿类型。
- 检查 Alpha Test 与程序化硬边。常规像素频率着色下，MSAA 对这些着色内部边缘的帮助有限；Alpha-to-Coverage 和样本频率着色可改变覆盖行为，需分别验证。
- 在 sRGB 与线性两种颜色状态下各做一次 Resolve，确认没有在编码值上直接平均。
- 单独显示运动向量，分别验证相机运动、骨骼动画、顶点动画与 UV 动画。
- 冻结相机只移动物体，确认向量方向与尺度正确。
- 关闭抖动，区分空间滤波与时域累积各自的贡献。
- 显示历史权重、拒绝遮罩与遮挡揭露区域。
- 用移动遮挡、高亮粒子做压力测试，观察鬼影与闪烁。
- 静止画面下观察收敛过程，确认若干帧后细节稳定增加。
- 关闭历史矫正对比：闪烁消失说明问题出在矫正，鬼影出现说明矫正确实必要。
- 相机瞬切后检查前几帧是否过锐带锯齿。

本机数值检查：[raster_models.py](../examples/revision/raster_models.py) 与 [test_raster.py](../examples/revision/test_raster.py)验证颜色盒裁剪的盒内、盒外和退化输入，以及两帧w不同时的UV运动量和Y轴方向，运行 `python -B 知识库/examples/revision/test_raster.py`。HLSL片段未构成完整TAA工程。

本机机制检查：CPU 权重展开得到5、10、15帧约2.17、5.13、9.78个等效样本，稳态约19；假设各样本独立且等方差。检查代码见 [reference.py](../examples/mechanisms/reference.py)，运行 `python 知识库/examples/mechanisms/reference.py`。引擎画面、GPU捕获与性能另外验证。
