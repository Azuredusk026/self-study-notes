# 光栅化、插值与深度模板

光栅化把三角形的连续覆盖转换为屏幕上的离散样本。深度和模板决定这些样本能否继续处理或写入结果。

## 专题阅读

- [[02_GPU与光栅化管线/光栅化与属性插值]]：光栅器将图元变成覆盖样本，再为片元计算属性。
- [[02_GPU与光栅化管线/深度缓冲与位置重建]]：深度缓冲保存投影后的可见性比较值。
- [[02_GPU与光栅化管线/基于深度的可见性优化]]：提前深度测试减少无效着色，深度预通道提前建立可见性，分层深度用保守深度范围判断整块遮挡。
- [[02_GPU与光栅化管线/Stencil与对象遮罩]]：模板缓冲保存有限位宽的标签，通过比较和更新操作选择片元。

## 验证方法

- 使用 Overdraw 或 Early-Z Counter 检查像素着色是否真的减少。
- 对比 Front-to-back 和 Back-to-front 绘制顺序。
- 关闭 Depth Write，观察后续物体的遮挡变化。
- 用极近 Near Plane 制造深度精度问题，再调整验证。
- 在帧捕获中检查 Depth Compare、Clear Value、Stencil Ref 和每个 Face 的操作。
- 启用 Depth Prepass 后核对后续比较方式。复用相同覆盖的通道可选 Equal，其他管线可能使用 LessEqual 或反向 Z 的对应比较；位移、Alpha 与样本覆盖必须一致。
- 切换 Reversed-Z 后检查 Clear Value 与比较函数是否同步修改。
- 把深度重建结果按固定距离取模输出为条纹，检查是否贴合场景表面。
