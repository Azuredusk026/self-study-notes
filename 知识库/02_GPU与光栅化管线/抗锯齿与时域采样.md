# 抗锯齿与时域采样

锯齿不是只发生在三角形边缘。几何覆盖、纹理、高光、阴影和透明测试都会产生高频信号。不同抗锯齿方法处理的信息不同。

## 超采样（SSAA）

用更高分辨率渲染，再过滤到目标分辨率。它同时改善几何、纹理和 Shader 锯齿，接近最直接的参考方案。

代价是几何、像素、带宽和内存都随采样数增加，实时项目很少全程使用。

## MSAA

MSAA 在每个像素保存多个 Coverage/Depth 样本，但通常只执行一次 Pixel Shader，再把结果写到覆盖样本。

它擅长处理三角形边缘，因为同一像素内多个样本可以表示部分覆盖。

它不能自动解决：

- Shader 内部的程序化硬边；
- 高频法线和高光；
- 纹理缩小；
- 没有使用 Alpha-to-Coverage 的 Alpha Test 边缘；
- 时域闪烁。

Deferred Rendering 使用多个 GBuffer 时，MSAA 会增加存储和解析复杂度，因此很多引擎改用时域方案。

## FXAA

FXAA 是单帧后处理。它根据亮度或颜色变化检测边缘，再沿边缘方向平滑。

优点是便宜、容易接入。缺点是没有真实子像素覆盖信息，可能漏掉边缘或模糊文字、纹理细节。它也不能解决随时间变化的闪烁。

## TAA 的基本目标

TAA 让每帧使用略微不同的子像素采样位置，再把多帧样本重投影到当前帧累积。它用时间换取更多样本。

完整流程通常包含：

1. 抖动投影矩阵；
2. 渲染当前帧颜色、深度和 Motion Vector；
3. 根据 Motion Vector 找到当前像素在上一帧的位置；
4. 采样历史颜色；
5. 判断历史是否仍有效；
6. 约束历史，避免它脱离当前邻域；
7. 混合当前帧与历史帧；
8. 保存为下一帧历史。

## Jitter

每帧把投影中心移动一个亚像素偏移，使几何在像素网格上的采样位置变化。常用 Halton 或其他低差异序列。

抖动需要进入当前/上一帧矩阵计算。否则 Motion Vector 和重投影会把相机 Jitter 误认为真实运动。

## Motion Vector 和重投影

运动向量表示当前像素对应表面从上一帧到当前帧的屏幕位置变化。

静态物体也会因相机移动产生向量。骨骼动画、顶点动画和程序化位移如果没有正确的上一帧位置，会出现拖影。

反向重投影的直觉是：当前像素减去它的运动，就得到上一帧的采样位置。具体符号取决于引擎 Velocity 定义。

## 历史为什么会失效

### Disocclusion

当前帧刚露出的背景，上一帧对应位置可能属于前景物体。历史颜色不能使用。可以比较重投影位置的深度、法线、Object ID 或 Material 信息判断。

### 光照和材质突变

闪光、粒子、透明、反射和程序化材质可能变化很快。历史权重太高会让变化拖尾。

### 采样落到屏幕外

历史 UV 超出范围时必须拒绝。

## Neighborhood Clamp

历史颜色可能落在当前局部颜色范围之外。常见做法是统计当前像素邻域的 Min/Max、均值和方差，再把历史裁剪到合理范围。

RGB 直接 Clamp 容易改变色相。实际方案可能使用 YCoCg 等颜色空间、Variance Clipping 或 Clip AABB。

Clamp 越强，鬼影越少，但时域稳定和超采样收益也越低。

## 混合权重

简单形式：

$$
C=\alpha C_{current}+(1-\alpha)C_{history}
$$

$\alpha$ 不是固定越小越好。它可以根据速度、深度差、颜色差、响应遮罩和历史长度变化。

## 常见伪影

| 现象 | 常见原因 |
|---|---|
| 拖影 | Motion Vector 缺失、历史权重过高、Disocclusion 判断失败 |
| 画面发糊 | 历史滤波过强、重建核过软、Jitter/锐化不匹配 |
| 闪烁 | 历史频繁拒绝、采样序列差、高频信号未预过滤 |
| 边缘漏光 | 深度/法线历史判断不够严格 |
| 动画表面游动 | Skinned/Vertex Animation 没有正确上一帧位置 |

## Temporal Upsampling

如果当前帧以低分辨率渲染，Jitter 和历史累积还可以重建更高分辨率输出。此时算法不仅抗锯齿，还要恢复缺失像素。

它更依赖高质量 Motion Vector、曝光一致性、历史拒绝和锐化。透明和后处理是在升采样前还是后执行，也会改变结果。

DLSS、FSR 等时域超分实现细节不同，但向引擎索取的信息契约相近：低分辨率颜色、深度、运动向量、抖动偏移、曝光、输出分辨率以及响应或透明遮罩。运动向量的空间、单位和是否包含 Jitter 必须与接口约定一致。

超分系统不能凭空恢复稳定细节。粒子、透明、反射、发光和顶点动画若缺少可靠运动信息，需要通过 Reactive Mask、Composition Mask 或专用 Pass 降低历史置信度。评估时应同时观察静止细节、快速运动、遮挡揭露和动态分辨率切换。

## 验证方法

- 单独显示 Motion Vector，检查相机、骨骼和顶点动画。
- 冻结相机，只移动对象，确认向量方向和尺度。
- 显示 History Weight、Rejection Mask 和 Disocclusion。
- 暂时关闭 Jitter，区分空间滤波和时域累积效果。
- 使用细线、重复纹理、移动遮挡和高亮粒子作为压力测试。
