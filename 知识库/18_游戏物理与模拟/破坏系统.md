# 破坏系统

一个物体碎开，不只是生成很多刚体。破坏系统先保存Chunk连接和支撑，再让冲击改变连接，失去支撑的连通块进入动态模拟。碎片生命周期与权威事件决定它能否用于玩法。

## 破坏

破坏系统通常预先用 Voronoi 等方式切分 Chunk，并建立连接图。冲击先改变连接强度，失去支撑的连通块再转成动态刚体。这样比运行时任意布尔切割稳定，也便于美术控制断面。

碎片数量必须有预算。远处可只播放替代动画或粒子，小碎片可以快速休眠、合并碰撞或不参与 Gameplay 结算。破坏结果影响玩法时，要由权威逻辑决定，表现层只负责播放对应状态。

## 激活流程

模型伪代码输入断裂连接与预算，连通计算以当前连接图为准。

```text
remove failed bonds
components = ConnectedComponents(chunkGraph)
for component without support:
    activate dynamic representation within budget
    use explicit proxy for excess fragments
```

## 验证方法

固定断裂事件比较连接分量，检查小碎片预算、睡眠与回收。联网破坏由权威状态确定，VFX只表现结果；实际断面与碰撞由资产验证。
