# 角色、布料、破坏与载具物理

角色、布料、破坏和载具都建立在碰撞与约束之上，但它们追求的控制感不同。角色需要可预测，布料需要视觉稳定，破坏需要可管理的碎片，载具需要对输入有连续反馈。统一底层不等于统一调参方式。

## Character Controller

常见角色控制器使用胶囊做 Sweep，而不是把玩家当普通 Dynamic 刚体。一次位移会先检测最早碰撞，再把剩余位移投影到接触平面形成 Sliding。Stepping 需要额外尝试“向上、向前、向下”三个阶段，并检查台阶高度和落点。

Slope Limit 通过地面法线与 Up 的夹角判断可站立区域。贴地检测需要容忍很小的间隙，但 Skin Width 过大又会让角色悬浮。移动平台要明确继承平台位移还是速度，并处理平台旋转。

跳跃初速度可由目标高度 h 推出：

$$
v_0=\sqrt{2gh}
$$

这里 g 使用重力加速度的正值。为了手感，起跳和下落可以使用不同重力倍率，但要把它当玩法规则，而不是物理常量。

## Ragdoll 与动画混合

Ragdoll 用刚体和关节近似骨骼。动画切入物理时要先把刚体对齐到当前 Pose，并从骨骼运动估计初速度。物理回到动画时不能瞬间夺回全部控制权，通常先选择骨盆或根节点对齐，再按权重混合到可恢复姿势。

关节角度、质量分布和碰撞层比增加求解迭代更重要。相邻骨骼互相碰撞、细长肢体惯性不合理和初始穿透，都会造成“抖成一团”。

## 布料与 XPBD

布料可以用质点和边约束表示。Verlet 或半隐式欧拉负责预测位置，约束求解负责恢复边长、弯曲和体积。PBD 直接修正位置，稳定且易控制；XPBD 为约束增加 Compliance，使软硬程度对时间步和迭代次数更稳定。

XPBD 的约束增量常写成：

$$
\Delta\lambda=\frac{-C(x)-\tilde{\alpha}\lambda}{\sum_i w_i\lVert\nabla C_i\rVert^2+\tilde{\alpha}},\qquad
\tilde{\alpha}=\alpha/\Delta t^2
$$

C 是约束误差，w 是逆质量，alpha 是 Compliance。Pinned Weight、碰撞厚度、自碰撞和阻尼需要一起调。渲染网格可以绑定到更低分辨率的 Physical Mesh，避免直接模拟所有顶点。

## 破坏

破坏系统通常预先用 Voronoi 等方式切分 Chunk，并建立连接图。冲击先改变连接强度，失去支撑的连通块再转成动态刚体。这样比运行时任意布尔切割稳定，也便于美术控制断面。

碎片数量必须有预算。远处可只播放替代动画或粒子，小碎片可以快速休眠、合并碰撞或不参与 Gameplay 结算。破坏结果影响玩法时，要由权威逻辑决定，表现层只负责播放对应状态。

## 载具

简化载具常用每个车轮的 Raycast 估计悬挂压缩量。弹簧力与压缩相关，阻尼力与压缩速度相关。轮胎模型再根据纵向滑移和侧偏角给出牵引力。Weight Transfer 会改变各轮法向载荷，因此加速、制动和转向不能只改车体速度。

Ackermann 转向让内外轮使用不同角度，差速器分配驱动扭矩。街机玩法可以加入额外下压力、横向稳定和漂移规则，但要放在清晰的车辆控制层，避免和底层接触求解互相打架。

## 系统集成

物理事件常驱动音频、VFX、相机和 Gameplay。事件数据应包含位置、法线、相对速度、材质和冲量，并在统一阶段消费。这样既能做表面音效和火花，也能限制同一帧大量接触造成的事件风暴。

PhysX、Jolt 等成熟物理库负责碰撞检测、刚体、约束、查询和求解器。选型要看目标平台、授权、确定性需求、Character/Vehicle/Cloth 能力、调试工具和升级成本。接入时由引擎适配层管理坐标单位、对象句柄、碰撞层、任务调度和事件回传，Gameplay 不应直接持有库内部指针。

Jolt 结构相对紧凑，适合需要阅读和定制底层的引擎；PhysX 生态与平台支持更广，并提供成熟的工程集成。库名称不能代替验证，项目仍要测试堆叠稳定性、CCD、场景查询、跨线程访问和极端帧时间。

### XPBD 距离约束

两个粒子的位置为 `x0`、`x1`，逆质量为 `w0`、`w1`。`compliance` 控制柔软度，`lambda` 在同一时间步的迭代间保留：

```cpp
Vec3 d = x1 - x0;
float length = Max(Length(d), 1e-6f);
Vec3 n = d / length;
float C = length - restLength;
float alpha = compliance / (deltaTime * deltaTime);
float deltaLambda = (-C - alpha * lambda) / (w0 + w1 + alpha);
lambda += deltaLambda;
x0 -= w0 * deltaLambda * n;
x1 += w1 * deltaLambda * n;
```

固定粒子的逆质量为 0。XPBD 用 `compliance / dt²` 减少刚度随时间步变化的问题，但迭代数和约束顺序仍影响结果。把时间步减半并保持相同物理时间，绳长误差应接近；差异很大时检查 `lambda` 的清零时机和单位。
