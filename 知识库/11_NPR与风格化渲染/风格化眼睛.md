# 风格化眼睛

眼睛只贴一张颜色图，会像印在脸上。角膜反射与虹膜内部颜色具有不同深度，视差和独立亮斑能表达这份层次。艺术化形状可以调整，层间遮挡与观察方向仍要一致。

## 眼球分层

眼球通常需要独立材质层：

- Iris/Pupil 可能在切线或局部空间做 Parallax；
- Cornea 高光与虹膜颜色分开；
- 眼白避免纯白并接收受控阴影；
- 上眼睑阴影和睫毛用专用 Mask；
- Look-at 时左右眼方向、汇聚距离和高光应稳定。

### 为什么眼睛需要深度感

风格化眼睛的画法虽然自由，但被普遍还原的几个特征都源自真实眼球结构，理解它们才知道该做什么、该省什么。

角膜曲面与不同介质折射率共同改变进入眼睛的光路，角膜与虹膜之间的前房含房水。实时眼睛通常把角膜表面反射和虹膜层分开近似，观察到的深度与亮斑取决于所用模型。

**折射**。透过前房看到的虹膜位置发生偏移，视觉上瞳孔与虹膜向内凹陷。侧面视角下这个偏移最明显，是眼睛看起来有深度的主要来源。实时实现通常用视差映射近似：以角膜为表面、虹膜为深度层，按视线方向偏移采样 UV。

**内部亮斑**。折射光路可能在虹膜层形成非均匀照明。它与角膜表面的镜面高光是两回事：高光在眼球表面、随光源方向移动；焦散在虹膜内部、位置与光线折射路径相关。风格化眼睛可以用独立亮斑近似这类焦散表现，但具体画法并不自动对应真实光学现象。

此外，上眼睑投下的阴影与眼眶上部的高光点也被广泛保留，它们提供眼睛的体积感。

风格化时可以自由改变虹膜图案、高光形状与颜色，但这几个结构特征若全部省略，眼睛会显得平贴在脸上。

## 分层求值轮廓

伪代码输入局部视线、角膜法线和虹膜高度层，输出分开的虹膜与角膜贡献。

```text
irisUv = ParallaxToIris(localView, irisDepth)
iris = SampleIris(irisUv) * eyelidShadow
cornea = EvaluateCorneaReflection(view, light, corneaNormal)
color = CombineLayers(iris, cornea)
```

## 验证方法

侧视检查虹膜偏移，转动眼球检查高光、睫毛与眼睑遮挡。眼球光学模型涉及角膜曲面和折射率，独立亮斑只是艺术近似，不能声明为完整焦散计算。
