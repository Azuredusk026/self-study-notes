# 植被风动与顶点变形

植被风动让枝叶沿锚点发生可控位移。根部需要固定，枝条主摆动与叶片细抖动使用不同频率；每个实例的相位要独立，才能避免整片树林同步摇摆。

## 从权重到位移

### 根部、枝条与叶尖

顶点色或UV可保存根部固定权重、枝条弯曲权重和叶片抖动权重。权重定义属于资产契约，制作与Shader使用同一通道约定。根部权重为零时位移也应为零，骨架或地面接点才能保持稳定。

基础正弦摆动可以先验证这条不变量。下面是世界空间HLSL机制片段，`windDirectionWS`为单位水平向量，`anchorWS`是实例固定锚点，`heightWeight`为0–1，振幅使用世界单位。

```hlsl
float phase = dot(anchorWS.xz, spatialFrequency) + instancePhase;
float swing = sin(timeSeconds * angularFrequency + phase);
float3 displacedWS = positionWS + windDirectionWS
                      * amplitudeWS * heightWeight * swing;
```

该片段是形变模型，尚未在引擎运行。固定锚点计算实例相位，顶点位置随时间变化也不会反过来改变相位。高度权重可用平方或曲线控制弯曲，接近叶尖时再叠加低振幅高频项。

### 阵风与空间变化

阵风用低频空间场改变振幅和方向。世界采样让邻近树木响应相似风场，实例相位提供局部差异。对象空间采样随模型移动，世界空间采样则需要处理大世界原点移动和时间精度。

位置偏移只改变顶点。弯曲较大时，原法线仍描述静态表面，光照会显得脱离运动；可对形变求导更新切线基底，或使用已知旋转变换同步方向。简单偏移适合小幅摆动，大幅形变要同时设计表面方向。

## 让所有通道看到同一运动

阴影、深度、本体和描边应使用相同位移函数和参数，运动向量还要用当前与上一帧参数计算两个位置。上一帧时间、风场和锚点需要明确保存；只用当前时间重算两帧，会得到错误运动向量。

Bounds包含最大可能位移，CPU剔除才能保守覆盖动画。LOD和Impostor切换时保持锚点、振幅与相位关系，必要时按屏幕贡献淡化高频抖动。形变参数重置、传送和原点移动时同步处理历史有效性。

## 验证与成本

先关闭细抖动只看主摆动，检查根部固定；再分别打开实例相位、阵风与法线更新。对照本体、阴影、深度和运动向量，定位出现差异的通道。

风动新增顶点计算和可能的纹理采样，多个Pass会重复执行。记录各LOD、阴影级联、描边和Alpha Clip路径，比较实际顶点调用与GPU时间。远景降低高频振幅，检查轮廓闪烁和Alpha覆盖。
