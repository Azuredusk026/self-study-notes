# 延迟补偿命中

射手看到目标还没进掩体，服务器收到射击时目标可能已经躲开。延迟补偿在有限窗口内查询射手对应的历史碰撞状态，再恢复当前世界。它处理命中公平性，不是把整局模拟回滚。



## 历史查询

伪代码输入经服务端校验的射击Tick与方向，碰撞历史由服务端保存。

```text
time = ValidateAndClampShotTime(session, inputTick, historyWindow)
historicalColliders = QueryColliderHistory(time)
hit = RaycastValidatedShot(historicalColliders, shot)
apply authoritative damage to current game state
```

命中时间、插值延迟与时钟估计按项目协议换算；不能接受任意客户端时间戳。动态门、平台和目标销毁还要规定历史有效性。

## 验证方法

构造高延迟射手与进入掩体目标，检查窗口内外行为。重复射击请求去重，回退只影响查询碰撞，音效和当前状态不重复推进。
