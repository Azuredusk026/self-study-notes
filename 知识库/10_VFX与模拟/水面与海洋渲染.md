# 水面与海洋渲染

水面渲染由三个相对独立的子问题组成：网格如何组织、波形如何生成、表面如何着色。三者可以自由搭配——同一套波形可以跑在不同的网格方案上，也可以配不同的着色模型。分开理解比整体记忆某个方案更有用。

## 网格如何组织

海面理论上无限大，而顶点预算有限。核心要求是近处密、远处疏，且随相机移动时密度分布保持稳定。

### 投影网格

把一个规则网格铺在**屏幕空间**，再投影到水平面上求交点。

它的特性由构造方式直接决定：顶点在屏幕上均匀分布，因此投影到世界空间后天然近密远疏，且顶点总数恒定不随视角变化——预算完全可控。

代价是顶点的世界位置每帧都在变。任何依赖顶点身份的数据（逐顶点缓存、累积状态）都无法使用，所有信息必须能够从世界位置实时求出。相机接近水平时，投影范围趋于无穷，需要额外的边界处理。

### 分层网格

以相机为中心铺设若干层同心网格，每向外一层网格间距翻倍。相机移动时整体跟随，并按网格间距对齐吸附。

吸附是关键：如果网格连续跟随相机，顶点的世界位置持续变化，波形会出现整体滑动感。按间距取整吸附后，顶点只在整格位置上跳变，波形保持钉在世界空间中。

层与层之间的接缝需要处理。相邻层顶点密度差一倍，边界上稀疏侧的顶点必须与密集侧对齐，否则出现裂缝。常见做法是在过渡带插入专门的接缝三角形，或让密集侧的边界顶点插值到稀疏侧的位置。

### 四叉树细分

按相机距离递归细分平面，与地形 LOD 的思路一致。灵活性最高，可以按海岸线、重要区域局部加密，代价是需要维护树结构与相邻节点的层级差约束。

### 硬件曲面细分

提交一张粗网格，由细分阶段按屏幕投影尺寸动态加密。实现简单，但相邻 Patch 的边细分因子必须一致，否则出现裂缝；且细分因子需用小数模式避免密度跳变。

这些方案可以组合：用分层网格确定粗略结构，再用细分阶段做最后一级加密。

## 波形如何生成

### Gerstner 波

Gerstner 波在正弦波的基础上增加了水平位移，让波峰变尖、波谷变平，比纯正弦更接近真实水面：

$$
\phi_i=k_i\mathbf D_i\cdot\mathbf P_{0,xz}-\omega_i t+\phi_{0,i},\qquad
\mathbf P=\mathbf P_0+\sum_i\begin{pmatrix}
Q_i A_i D_{i,x}\cos\phi_i\\
A_i\sin\phi_i\\
Q_i A_i D_{i,z}\cos\phi_i
\end{pmatrix}
$$

$\mathbf{D}_i$ 是 XZ 平面上的单位传播方向，$A_i$ 是长度单位的振幅，$k_i=2\pi/\lambda_i$ 是波数，$\omega_i$ 是弧度每秒的角速度。$\phi_{0,i}$ 是初相位，$Q_i$ 控制水平位移比例。$Q$ 过大时顶点会互相穿越，水面自交出现翻折。

法线可以解析求导得到，不必依赖差分——这是 Gerstner 相对高度图方案的一个优势。

叠加数个波即可得到可用效果，成本低，适合移动端与中小水体。

### 顶点评估

输入是平面网格的顶点位置与一组波参数，输出是偏移后的位置与解析法线。下面是一个波的情形，多个波在循环中累加：

```hlsl
// 每个波携带：方向 dir（单位向量）、波数 k、振幅 A、角速度 w、陡峭度 Q
float3 pos = basePos;
float phase = k * dot(dir, basePos.xz) - w * time;
float s = sin(phase), c = cos(phase);

pos.xz += dir * (Q * A * c);   // 水平位移，Q 控制波峰尖锐度
pos.y  += A * s;               // 竖直位移

// 解析法线：对 Gerstner 位移求偏导，不必用差分
float wa = k * A;
float3 tangent  = float3(1 - Q * wa * s * dir.x * dir.x,
                         wa * c * dir.x,
                        -Q * wa * s * dir.x * dir.y);
float3 binormal = float3(-Q * wa * s * dir.x * dir.y,
                         wa * c * dir.y,
                         1 - Q * wa * s * dir.y * dir.y);
float3 normalWS = normalize(cross(binormal, tangent));
```

验证方法是把 $Q$ 调大：波峰应变尖、波谷变宽；$Q$ 过大导致顶点互相穿越时，能直观看到水面翻折。法线部分可把 $A$ 设为 0 验证，此时法线应全部竖直向上。

### FFT 海面

基于海洋学的经验波谱（如 Phillips 谱）在频域生成一张随机振幅场，再通过逆快速傅里叶变换转换到空间域，得到位移与法线贴图。

相比手工叠加若干个波，它一次性生成成千上万个频率分量，统计特性符合真实海洋观测，大范围海面的表现明显更自然。

代价是需要每帧执行若干次 FFT（通常在 Compute Shader 中完成），并且结果是一张**周期性平铺**的贴图——这直接引出下一个问题。

## 平铺重复

无论是少量 Gerstner 波还是 FFT 生成的贴图，远景俯视时都会暴露明显的重复图案。人眼对规则重复极其敏感，这是水面观感的主要破绽之一。

几种应对，通常叠加使用：

**多尺度叠加**。用两到三套不同周期、不同旋转角度的波形叠加。不同尺度与角度能让重复特征更难辨认。只有周期能写成同一基础单位的整数倍、方向也兼容时，才能按最小公倍数讨论精确重复周期；旋转后的二维图案通常不能用这条一维结论概括。

**波数与方向的选取**。Gerstner 方案中，避免各波的频率成简单整数比、方向过于集中。方向分布在一个主风向附近的扇形内比完全随机更真实，也更不容易形成规则干涉图案。

**低频扰动**。用一张大尺度的低频噪声调制波的振幅或 UV，打破规律性。成本低，效果明显。

**距离衰减**。远处本就看不清细节，随距离降低高频波的振幅，同时提高法线贴图的 Mip 级别。这既减轻了重复感，也缓解了远处法线的高频闪烁。

最后一点值得单独强调：远处水面的法线闪烁是普遍问题。大量亚像素级的高频法线在时域上剧烈跳变，即使有时域抗锯齿也难以稳定。让远处的法线收敛到平均朝向（接近水平）是必要的处理。

## 表面着色

### 反射与折射

水面的反射率随视角变化剧烈：俯视时主要看到水下，掠射时接近镜面。这由 Fresnel 项描述，是水面观感最重要的单一因素。

环境贴图查询成本较低，但内容更新受捕获策略限制。平面反射增加一个镜像视图，成本取决于分辨率、剔除和所启用的通道；屏幕空间反射复用已有画面，却缺少屏幕外和遮挡后的内容。三者没有固定的成本排序。实践中常以屏幕空间反射为主，失败处回退到环境贴图。

折射通常用扰动后的 UV 采样当前场景颜色实现。两个必须处理的细节：采样位置要按水下深度与折射强度偏移，且**必须防止采样到水面之前的物体**——否则岸边会出现水下颜色渗到岸上的错误。做法是比较采样点的深度，若该处物体在水面之上则退回未扰动的 UV。

### 水体颜色与透光

水的颜色来自体积吸收：光在水中传播越远，被吸收越多，且不同波长的吸收率不同（红光衰减最快，因此深水偏蓝绿）。

简化模型是按水面到水底的距离做指数衰减，对 RGB 使用不同的衰减系数：

$$
C = C_{bottom}\cdot e^{-\boldsymbol{\sigma} d} + C_{water}\left(1-e^{-\boldsymbol{\sigma} d}\right)
$$

$d$ 是光在水中的路径长度；屏幕实现常用同一线性观察空间的水面与水底深度差近似，但斜视和折射时它不等于真实路径，$\boldsymbol{\sigma}$ 是三个通道各自的衰减系数。这比直接用透明度混合更符合观察——浅滩自然透出底色，深水收敛到水体固有色。

### 泡沫

泡沫出现在两类位置，判据不同。

**波峰泡沫**。判据不是高度，而是**表面的形变程度**。Gerstner 波中可以用雅可比行列式判断水平压缩程度，压缩剧烈处即波峰破碎位置；更简化的做法是用法线的偏导数或曲率，变化剧烈处生成泡沫。

用高度做判据是常见的错误，它会让所有波峰不分强弱地一律泛白，看起来像一层白纱而非破碎的浪花。

**岸边泡沫**。由水面到岸边地形的距离决定，通常从深度缓冲比较得到。距离越近泡沫越强，并叠加一张随时间流动的噪声表现拍岸的动态。

两类泡沫都用同一张泡沫纹理，但强度遮罩的来源完全不同。

### 岸边过渡

浅水区需要同时处理几件事：水体颜色变淡透出底色、泡沫增强、以及波高衰减——浅水波会发生折射、浅化和破碎，不能把深水波直接延伸到岸上。

波高衰减容易被忽略，缺失时会看到大浪直接穿过沙滩的穿帮。一种便于美术控制的近似是按水深衰减振幅，使岸线处回到静止水面。它用于避免穿岸，完整浅水动力学还要描述浅化和破碎。

## 验证方法

- 相机贴近水面平移，检查波形是否钉在世界空间中，出现整体滑动说明网格跟随没有做整格吸附。
- 拉到高空俯视，观察是否出现规则重复图案。
- 沿网格分层边界检查是否有裂缝或密度突变。
- 在浅滩处检查水体颜色是否平滑过渡、波高是否随水深衰减。
- 关闭折射扰动对比，检查岸边是否有水下颜色渗到岸上。
- 远景静止观察法线闪烁，确认距离衰减生效。
- 单独输出泡沫遮罩，确认波峰泡沫只出现在形变剧烈处而非所有波峰。

本机机制检查：30 组固定种子的 CPU 输入中，解析切向量与中心差分吻合；这只验证单波公式，没有执行水面 Shader。检查代码见 [reference.py](../examples/mechanisms/reference.py)，运行 `python 知识库/examples/mechanisms/reference.py`。引擎画面、GPU捕获与性能另外验证。
