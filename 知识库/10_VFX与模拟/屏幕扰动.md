# 屏幕扰动

热浪让背景扭曲，但屏幕颜色只包含已绘制内容。屏幕扰动把偏移场变成UV，采样场景快照再合成。执行时机、深度拒绝与源目标分离决定边缘是否会吸入错误前景。

## 屏幕扰动与折射

屏幕扰动通常采样场景颜色：

$$
\mathbf{uv}'=\mathbf{uv}+\mathbf{d}\,k
$$

$\mathbf{d}$ 可由法线/噪声的 RG 映射到 $[-1,1]$，$k$ 是强度。

需要限制偏移，避免采到物体轮廓外的错误前景。场景颜色只包含已经渲染的内容，因此执行时机、透明队列和相机堆叠都会改变结果。

真正物理折射还涉及 IOR、厚度和入射方向。简单屏幕偏移只是视觉近似，在屏幕边缘和遮挡关系上天然缺信息。

## 偏移采样

HLSL片段输入offset无单位UV，source是一份可采样快照，不能同时写同一子资源。

```hlsl
float2 sampleUv = clamp(uv + offset, validMinUv, validMaxUv);
float3 color = SceneColor.SampleLevel(LinearClamp, sampleUv, 0).rgb;
```

### 前景拒绝

偏移坐标处若是位于扰动面之前的栏杆，直接采样会把栏杆颜色拉到背景里。先在候选 UV 读取深度并线性化，和该采样方向下扰动面的观察深度比较；前景样本退回原 UV。对于近似平面的小偏移，可以用当前片元深度近似，曲面或大偏移则需要重建采样射线与扰动面的关系。

```text
candidateUV = clamp(uv + offsetPixels / renderSize, validMinUV, validMaxUV)
candidateDepth = LinearDepth(SceneDepth(candidateUV))
if candidateDepth < distortionDepthAt(candidateUV) - tolerance:
    candidateUV = uv
color = SceneColorSnapshot(candidateUV)
```

`distortionDepthAt` 是几何查询接口，平面可做射线平面求交；代码不假装屏幕深度包含这份表面。像素偏移除以实际渲染尺寸，动态分辨率改变时才能保持约定的纹素尺度。边界限制范围只保证坐标合法，会把边缘颜色拉长；可以把接近屏幕边缘的扰动权重淡出，避免把缺失屏外内容显示成一条色带。

## 验证方法

把扰动强度设为零，与原图一致；在物体边缘、屏幕外和不同透明顺序检查缺失。真实折射还涉及IOR、厚度与遮挡，屏幕偏移只提供视觉近似。
