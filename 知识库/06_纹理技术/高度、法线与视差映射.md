# 高度、法线与视差映射

一张平面纹理可以描述颜色，也可以描述表面的局部形状。法线贴图改变着色方向，视差映射移动纹理坐标，位移映射才真正改变几何位置。三者解决的问题和产生的遮挡不同。

## 高度图、深度图和法线贴图

高度图（Height Map）保存表面相对基准面的高度。常见约定是白色高、黑色低。深度图在视差算法中常表示从表面顶层向内的距离，因此可能使用：

$$
d(u,v)=1-h(u,v)
$$

资产和 Shader 必须使用同一约定。约定相反时，凸起会显示成凹陷。

法线贴图保存的是局部表面方向。它能改变漫反射和高光，却不能改变纹理坐标，也不能产生真实轮廓和几何遮挡。高度图可以离线转换成法线贴图，但法线积分回高度通常没有唯一解。

## 为什么在切线空间计算

UV、高度图和法线贴图都附着在表面的切线坐标系中。这里把观察方向 $\mathbf V$ 定义为从表面指向相机，并让切线空间的 $V_z>0$。变换后：

- $V_x,V_y$ 表示视线沿纹理平面的移动方向；
- $V_z$ 表示视线离开表面的程度；
- UV 偏移可以直接沿 $V_{xy}$ 计算。

TBN 的生成规则、镜像 UV 手性和法线贴图 Y 轴约定仍由 [[04_光照模型与PBR/法线贴图、切线空间与IBL]] 负责。视差和法线必须采样同一组偏移后的 UV，否则凹凸位置会错开。

## 基础视差映射

把表面看成厚度为 $s$ 的高度层。使用一次高度采样估计视线在层内走过的距离：

$$
\Delta \mathbf{uv}=\frac{\mathbf V_{xy}}{\max(V_z,\varepsilon)}d(u,v)s
$$

$$
\mathbf{uv}'=\mathbf{uv}-\Delta\mathbf{uv}
$$

$s$ 是高度缩放，$\varepsilon$ 防止掠射角除以接近零的 $V_z$。减号取决于观察向量定义和纹理坐标方向，结果反向时应先检查空间和符号。

下面的 GLSL 函数使用白色为高处的高度图，输入观察方向已经归一化到切线空间：

```glsl
vec2 ParallaxUV(
    sampler2D heightMap,
    vec2 uv,
    vec3 viewDirTS,
    float heightScale)
{
    float depth = 1.0 - texture(heightMap, uv).r;
    float safeZ = max(viewDirTS.z, 0.05);
    vec2 ray = viewDirTS.xy / safeZ;
    return uv - ray * depth * heightScale;
}
```

这段代码只有一次高度采样，适合较浅、变化平缓的表面。高度变化大时，一次采样无法找到视线与高度场的真实交点。

## Offset Limiting

基础公式在掠射角会因为 $1/V_z$ 产生很大的偏移。Offset Limiting 省略除法，直接使用 $V_{xy}$：

$$
\Delta \mathbf{uv}=\mathbf V_{xy}d(u,v)s
$$

偏移更稳定，斜视时的深度感也会减弱。它适合高度很浅、稳定性优先的材质。

## 陡峭视差映射

陡峭视差映射（Steep Parallax Mapping）把深度范围 $[0,1]$ 分成多层。算法沿切线空间视线逐层移动 UV，并比较“当前射线深度”和“高度场深度”。第一次穿过表面时停止。

观察越接近表面，射线在 UV 平面走得越远，需要更多层：

$$
N=lerp(N_{max},N_{min},|V_z|)
$$

固定层数容易在正视时浪费采样，在掠射角出现台阶。动态层数把预算放到更困难的角度。

## 视差遮蔽映射

视差遮蔽映射（Parallax Occlusion Mapping，POM）在首次穿过后，使用穿过前后的两个样本做线性插值，得到更连续的交点。

下面的核心循环省略了材质采样。`depthMap` 保存从顶层向内的深度，黑色表示顶层：

```glsl
vec2 ParallaxOcclusionUV(
    sampler2D depthMap, vec2 uv, vec3 viewDirTS,
    float heightScale, float minLayers, float maxLayers)
{
    float layers = mix(maxLayers, minLayers, abs(viewDirTS.z));
    float layerStep = 1.0 / layers;
    vec2 uvStep = viewDirTS.xy / max(viewDirTS.z, 0.05)
                * heightScale / layers;
    float rayDepth = 0.0;
    float surfaceDepth = texture(depthMap, uv).r;

    while (rayDepth < surfaceDepth) {
        uv -= uvStep;
        rayDepth += layerStep;
        surfaceDepth = texture(depthMap, uv).r;
    }

    vec2 prevUV = uv + uvStep;
    float after = rayDepth - surfaceDepth;
    float before = texture(depthMap, prevUV).r
                 - (rayDepth - layerStep);
    float t = before / max(before + after, 1e-5);
    return mix(prevUV, uv, t);
}
```

`before` 和 `after` 是交点两侧的深度误差。线性插值减少分层边界，但高度场本身仍是离散纹理，结果受分辨率、过滤和层数影响。

## UV 导数和 Mipmap

POM 会在循环中多次读取变化后的 UV。循环次数或分支在相邻像素间不一致时，隐式导数的 LOD 选择可能不稳定。可以在进入循环前保存原始 UV 的 `dFdx/dFdy`，再使用 `textureGrad`；HLSL 中对应 `SampleGrad`。

高度图也需要 Mipmap，但普通平均会改变高低峰形状。远处通常允许减弱高度缩放或层数，把稳定性和采样成本放在细小视差之前。

## 边界和局限

- 偏移后的 UV 可能超出纹理范围。平铺材质可以 Wrap，独立面片可以 Clamp 或丢弃片元。
- 视差只改变采样位置，模型轮廓、深度缓冲和碰撞保持原几何形状。
- 基础 POM 不包含高度场自阴影。额外沿光线步进可以近似自阴影，同时增加采样成本和噪声。
- 大高度、薄轮廓和近距离剪影适合几何位移或 Tessellation。
- 掠射角需要限制偏移、增加层数或渐隐效果，避免纹理拉伸和 UV 跳变。
- 动态循环的成本随角度和内容变化，需要在目标 GPU 上检查 Shader 指令、纹理采样和 Wave 发散。

## 最小验证

1. 使用斜光照的单个四边形，准备棋盘色、高度和法线三张可对齐纹理。
2. 依次显示原始 UV、基础视差、陡峭视差和 POM。
3. 固定相机后把层数设为 4、16、64，观察台阶和采样成本。
4. 将高度缩放设为 0，确认所有纹理回到原始 UV。
5. 旋转相机到掠射角，检查偏移方向、UV 越界和层数变化。
6. 单独显示偏移后的 UV 与最终深度误差，定位凹凸翻转和交点错误。
