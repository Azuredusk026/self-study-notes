# 个人游戏开发知识地图

知识库按“基础机制 → 画面与内容 → 引擎系统 → 游戏系统 → 生产管线”组织。领域编号用于稳定排序，不代表唯一的学习顺序。

正式领域覆盖 00-21。课程笔记保留课堂语境，正式文章负责跨课程去重、补足机制和建立知识关系。

## 建议主线

```text
数学、算法与编程
  ├─ GPU、Shader、渲染与性能
  ├─ 引擎架构、资源、任务与音频
  ├─ 物理、Gameplay、AI 与网络
  └─ 资产工具、AIGC 与 Agent
```

不需要一次按顺序读完。遇到项目问题时可以从对应主题进入，再沿双链补前置知识。

## 基础层

### 01 数学、采样与信号

解释渲染中反复出现的数学语言：向量、矩阵、空间变换、旋转、插值、频率、采样、积分和球谐函数。

### 02 GPU 与光栅化管线

解释一帧从 CPU 提交到屏幕输出的过程，以及光栅化、深度、模板、剔除、透明和抗锯齿为什么这样工作。

### 03 Shader 编程

解释 Shader 的数据流、编译、变体、Compute Shader 和 GPU 线程执行模型。

## 表面与画面层

### 04 光照模型与 PBR

解释 BRDF、微表面模型、PBR 材质、切线空间、法线贴图和 IBL。

### 05 光照、阴影与 GI

解释直接光、Shadow Map、PCF/PCSS、烘焙光照、Probe 和实时全局光照。

### 06 纹理技术

解释纹理采样、过滤、Mipmap、压缩、UV、图集、流送和虚拟纹理之间的关系。

### 07 颜色管理与后处理

解释 Linear/sRGB、Alpha、HDR、曝光、Tone Mapping、Bloom 和常见屏幕空间效果。

## 内容表现层

### 08 几何与网格

解释网格数据、缓存、简化、LOD、地形和程序化资产。

### 09 动画系统

解释骨骼蒙皮、动画状态、混合、IK、压缩、面部、布料和毛发。

### 10 VFX、体积与模拟

解释 CPU/GPU 粒子、常用 VFX 材质、大气散射、体积云、实时模拟和特效性能。

- [[10_VFX与模拟/大气散射、天空与体积云]]

### 11 NPR 与风格化渲染

解释 Toon Ramp、面部 SDF、头发、描边、Billboard 假深度和场景风格统一。

### 12 光线追踪与现代渲染

解释光线求交、BVH、实时光追、降噪、ReSTIR、GPU-Driven 和 Nanite。

### 15 资产与工具管线

解释 DCC、数据交换、资产验证、编辑器工具、版本控制和 CI。

### 16 编程与数据结构

### 17 AIGC 与 Agent 管线
