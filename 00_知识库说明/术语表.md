# Technical Art 术语表

术语表只统一叫法和搜索入口，不代替正文解释。

| 主叫法 | 英文或全称 | 别名与说明 |
|---|---|---|
| 技术美术 | Technical Art / TA | 连接美术、程序、设计和生产流程的技术岗位 |
| 渲染管线 | Rendering Pipeline | 区分 GPU 固定/可编程管线和引擎渲染架构 |
| 顶点着色器 | Vertex Shader | VS |
| 像素着色器 | Pixel Shader | Direct3D 常用；OpenGL/Vulkan 常称 Fragment Shader |
| 片元 | Fragment | 光栅化产生的候选样本，不一定成为最终像素 |
| 光栅化 | Rasterization | 将图元覆盖转换为片元/样本的过程 |
| 裁剪空间 | Clip Space | 齐次裁剪发生的空间 |
| 归一化设备坐标 | Normalized Device Coordinates | NDC；透视除法后的坐标 |
| 深度缓冲 | Depth Buffer | 常称 Z Buffer，但存储值不必等于线性视空间 Z |
| 提前深度测试 | Early-Z | GPU 在像素着色前尽量完成深度拒绝 |
| 分层深度 | Hierarchical Z / Hi-Z | 用深度层级快速判断区域遮挡 |
| 模板缓冲 | Stencil Buffer | 保存小整数标签并执行模板测试 |
| 剔除 | Culling | 包含背面、视锥和遮挡剔除，不等同于像素深度测试 |
| 混合 | Blending | 输出合并阶段组合源颜色和目标颜色 |
| 预乘 Alpha | Premultiplied Alpha | RGB 已乘 Alpha 的表示和混合约定 |
| 时域采样 | Temporal Sampling | 利用多帧不同采样位置重建结果 |
| 时域抗锯齿 | Temporal Anti-Aliasing | TAA |
| 运动向量 | Motion Vector / Velocity Buffer | 供历史重投影使用的屏幕空间位移 |
| 着色器变体 | Shader Variant | 由关键字、平台、Pass 等条件形成的编译版本 |
| 关键字 | Shader Keyword | 控制条件编译或运行时分支，需区分引擎实现 |
| 计算着色器 | Compute Shader | 不依赖传统图形管线的通用 GPU 计算阶段 |
| 线程组 | Thread Group / Workgroup | 一组可以共享组内存并同步的 GPU 线程 |
| 波前 | Wave / Warp | GPU 按 SIMD/SIMT 方式一起执行的线程集合 |
| 分支发散 | Branch Divergence | 同一 Wave 中线程走不同控制路径造成串行化 |
| 双向反射分布函数 | Bidirectional Reflectance Distribution Function | BRDF |
| 基于物理的渲染 | Physically Based Rendering | PBR；强调可解释材质和光照约束，不等于照片写实 |
| 法线分布函数 | Normal Distribution Function | NDF；描述微表面法线分布 |
| 菲涅尔项 | Fresnel Term | 反射率随观察角变化 |
| 几何项 | Geometry Term | 微表面遮蔽与阴影项 |
| 切线空间 | Tangent Space | 由 Tangent、Bitangent、Normal 构成的局部基底 |
| 图像光照 | Image-Based Lighting | IBL |
| 阴影贴图 | Shadow Map | 从光源视角保存深度并做可见性比较 |
| 百分比渐近过滤 | Percentage-Closer Filtering | PCF；过滤深度比较后的可见性结果 |
| 百分比渐近软阴影 | Percentage-Closer Soft Shadows | PCSS；遮挡搜索后使用可变过滤半径 |
| 级联阴影贴图 | Cascaded Shadow Maps | CSM |
| 纹素 | Texel | 纹理中的离散元素 |
| 纹理过滤 | Texture Filtering | 处理采样位置与纹素不一一对应的问题 |
| 多级渐远纹理 | Mipmap | 常直接写 Mipmap；保存逐级缩小的纹理 |
| 各向异性过滤 | Anisotropic Filtering | 改善倾斜表面的非均匀纹理缩小 |
| 纹理图集 | Texture Atlas | 将多张纹理放进同一资源以减少切换或组织数据 |
| 虚拟纹理 | Virtual Texture | 按页管理超大纹理的寻址、缓存和流送 |
| 线性空间 | Linear Space | 光照和颜色运算使用的线性数值空间 |
| sRGB | Standard RGB | 同时涉及色域和非线性传递函数；不能简单等同于 Gamma 2.2 |
| 高动态范围 | High Dynamic Range | HDR |
| 色调映射 | Tone Mapping | 将场景高动态范围映射到显示范围 |
| 延迟渲染 | Deferred Rendering | 先保存表面属性，再集中执行屏幕空间光照 |
| 几何缓冲 | GBuffer | Deferred Geometry Pass 输出的多组表面属性缓冲 |
| 分块光照 | Tiled Lighting | 按屏幕 Tile 建立光源列表 |
| 簇状光照 | Clustered Lighting | 在屏幕 XY 和深度维度划分 Cluster |
| 渲染通道 | Render Pass | 需要结合图形 API、引擎和算法上下文理解 |
| 命令缓冲 | Command Buffer | 记录待提交 GPU 的命令序列 |
| 渲染图 | Render Graph | 用资源依赖描述 Pass，并管理生命周期、同步和别名复用 |
| 绘制调用 | Draw Call | CPU 向图形 API/GPU 提交一次绘制工作；不能只按数量判断成本 |
| GPU 实例化 | GPU Instancing | 共享几何和材质，一次提交多个实例数据 |
| 空间加速结构 | Acceleration Structure | 用层级包围体等减少不必要求交 |
| 包围体层次结构 | Bounding Volume Hierarchy | BVH |
| 底层/顶层加速结构 | BLAS / TLAS | 硬件光追中常见的几何层和实例层结构 |
| 非真实感渲染 | Non-Photorealistic Rendering | NPR；也常称风格化渲染，但两者范围不完全相同 |
| 符号距离场 | Signed Distance Field | SDF；带符号的最近表面距离 |
| 广告牌 | Billboard | 视觉朝向相机的面片或对象，不代表深度必须跟随面片方向 |
| 图形调试器 | Graphics Debugger | RenderDoc、PIX、Nsight Graphics 等单帧捕获工具 |
| 数字内容创作工具 | Digital Content Creation Tool | DCC，例如 Maya、Blender、Houdini |
| 数据血缘 | Data Lineage | 资产由哪些输入、模型、参数和步骤生成 |
